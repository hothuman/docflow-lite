# Изменения DocFlow

## 1.0.0 — 26.10.2026

Подготовлен стабильный выпуск Core + Service после приёмки RC1 владельцем в Windows/Word. Добавлены атомарная отмена Core, read-only проверка схемы до восстановления, защита Windows-путей, exact-source/SBOM gates и обновлённая Windows-среда. Фактические файлы и проверки — в BUILD-INFO поставки. Коммерческий правовой GO остаётся отдельным.


## 1.0.0rc1 — подготовка, не опубликована как stable

Отмена Core с очисткой частичного пакета и повтором; структурная проверка SQLite до восстановления/миграции; запрет неоднозначных путей Windows. Exact-состав Source/Portable, SBOM и отдельные стадии RC/stable. CPython 3.14.10 / Qt 6.12.0 / setuptools 84.2.1 после проверки advisories. Сайт получает понятный бриф вместо отключённой формы; новые данные не собираются. Утверждённые две правки маркировки LICENSE, прежние права сохранены.


## 0.3.0a6

Предварительная версия Core + Service, концепция «Ночной инструмент».

- Общая тёмная тема программы и сайта, явное переключение Core/Service и контекстная навигация.
- Путь подготовки документов Core, доступные действия и сохранение текстовых подписей в небольшом окне.
- Паспорт ремонта с раздельными номерами аппарата/обращения и подсказкой по фактическому статусу.
- Поиск по деловым полям исключает скрытые UUID и служебные данные, сохраняя номера, клиентов, аппараты, статусы и позиции.
- Версии смет, ручные согласования, точные финансовые записи, история, документы, вложения и проверяемые копии Service.
- Перенос длинных рядов действий; сохранение ширин таблиц через INI.
- Изоляция DLL при Windows-сборке: чужие ICU из сторонних инструментов не включаются в поставку.
- Условия оригинального продукта, сведения о Qt/LGPL, инструкции, поддержка и комплект выпуска.

Конкретное происхождение каждого файла: BUILD-INFO и SHA256SUMS выбранного выпуска. Новые проверки не переносятся на старые сборки автоматически.
