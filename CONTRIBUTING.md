# Работа с исходниками DocFlow

DocFlow использует собственные [условия оригинальных компонентов](LICENSE.txt). Публичность репозитория не назначает открытую лицензию MIT/GPL на код приложения. Лицензии сторонних компонентов остаются самостоятельными.

Перед работой прочитайте [AGENTS.md](AGENTS.md), [архитектуру](docs/ARCHITECTURE.md) и [инструкцию разработки](docs/DEVELOPMENT.md). Сначала воспроизведите дефект на синтетических данных. Исправляйте причину, сохраняйте совместимость и добавляйте регрессию для существенного изменения.

Не включайте чужой код, изображения или данные без подтверждённых прав. Условия принятия существенного внешнего вклада согласуются с правообладателем до его включения; автоматическая передача исключительных прав не предполагается.

PR должен объяснять проблему, поведение после исправления и выполненные проверки. Не меняйте лицензии, правообладателя, бренд или схему данных попутно. Пользовательские данные, секреты, среды разработки и готовые сборки в Git не добавляются.

Перед передачей обновите FILE_HASHES.json, проверьте документацию и выполните подходящие проверки. Финальная сборка проверяется отдельно от запуска Python. Выпуски и production изменяются только в разрешённом объёме.
