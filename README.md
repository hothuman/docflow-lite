# DocFlow Lite 0.1.1

Публичный сайт: https://docflow-lite.rostg2007.chatgpt.site/ . Демо-ZIP и видео доступны и проверены по SHA256. GitHub: https://github.com/hothuman/docflow-lite . Инфраструктура публикации описана в `docs/LAUNCH.md`.

Локальное приложение: XLSX/CSV → ваши DOCX-шаблоны → комплект документов по каждой записи и отчёт об ошибках. В этом архиве находится первая рабочая версия из исходников, сайт и демонстрационные материалы. Готового Windows EXE пока нет.

## Быстрый запуск в Windows

1. Установите Python **3.12** с официального python.org, если его ещё нет. При установке оставьте Python Launcher (`py`).
2. Распакуйте весь архив в отдельную папку, например `C:\Projects\DocFlow`.
3. Откройте `start_windows.bat`. При первом запуске он создаст отдельную среду `.venv` и установит бесплатные зависимости. Для установки нужен интернет. Для генерации документов интернет не используется.
4. Нажмите **«Открыть демопример»**. Просмотрите вкладки **«Данные»** и **«Предпросмотр»**.
5. Выберите папку результата и нажмите **«Создать пакет документов»**.

Генерация и проверка используют загруженную копию таблицы и шаблонов. Если вы изменили исходный файл, выберите его заново, чтобы обновить данные в приложении.

Ожидаемый результат примера: **4 DOCX, 2 обработанные записи, 1 пропущенная запись**. В третьей записи намеренно пропущена услуга и указана отрицательная сумма. Это две ошибки одной записи, а не две пропущенные записи.

Готовые документы уже есть в `demo-output/`: их можно открыть без установки Python. Исходная таблица и шаблоны находятся в `src/docflow/examples/`.

Проверено в Linux на Python 3.12.14. Windows Launcher, установка зависимостей на Windows и EXE ещё не проверены на Windows. Если запуск не удался, окно BAT оставит сообщение об ошибке; пришлите его текст.

## Запуск из терминала

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[gui,dev]"
.venv\Scripts\python.exe -m docflow.gui
```

Linux/macOS, для разработки:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[gui,dev]'
.venv/bin/python -m docflow.gui
```

CLI использует ту же логику:

```bash
python -m docflow demo --out ./docflow-output
python -m docflow check src/docflow/examples/profile.json
python -m docflow preview src/docflow/examples/profile.json --row 1 --template 1
python -m docflow run src/docflow/examples/profile.json --out ./docflow-output
python -m pytest -q
```

Коды завершения CLI: `0` — без ошибок данных; `2` — проверка/генерация завершена, есть ошибочные записи; `1` — ошибка файлов, настроек или сохранения. Для встроенного демо код `2` ожидаем.

## Свой сценарий

В первой строке таблицы укажите уникальные названия столбцов. В документ Word добавьте переменные `{{client}}`, `{{amount}}` и т. п. Имена допускают буквы, цифры и подчёркивание, начинаются с буквы или подчёркивания. Можно использовать кириллицу. Загрузите таблицу, добавьте один или несколько шаблонов, сопоставьте переменные и выберите проверки. Сохраните JSON-настройки, чтобы повторить запуск.

Есть проверки обязательности, неотрицательного числа, формата email и даты `ГГГГ-ММ-ДД`. Проверка email проверяет только внешний формат, не существование адреса. Числа в DOCX сохраняют исходное текстовое представление; валютные вычисления не выполняются.

## Ограничения версии

- Текстовый предпросмотр; вёрстку результата проверяйте в Word/LibreOffice.
- До 5000 записей, 100 столбцов, 20 шаблонов; входной файл до 20 МБ. Это установленные лимиты, а не результат нагрузочного теста на всех устройствах.
- XLSX: по умолчанию активный лист, другой лист можно указать в JSON `sheet`. Формулы и ошибки Excel запрещены — замените их значениями в копии таблицы. Не все пользовательские числовые форматы Excel воспроизводятся; идентификаторы лучше хранить текстом. Простой формат `0000` поддерживается.
- CSV: UTF-8/UTF-8 BOM и Windows-1251; разделители `;`, `,`, табуляция. Автоопределение подходит не для каждого неоднозначного файла; кодировку можно задать в JSON.
- DOCX: простые переменные в обычном тексте, таблицах, вложенных таблицах и колонтитулах. Формат подставленного текста берётся от первого фрагмента переменной. Оформление остального содержимого сохраняется при замене XML текста.
- Нет циклов, условий, выражений, повторяемых строк и вставки изображений по переменной. Переменные в надписях, примечаниях, правках, абзацах с табуляцией/разрывами не поддерживаются. Поля Word, макросы, внешние связи и встроенные объекты отклоняются.
- Не закрывайте приложение во время генерации. Прерывание питания может оставить скрытую временную папку `.docflow-*`, но не перезапишет исходники.
- Программа не шифрует результаты. DOCX и названия папок могут содержать введённые данные. Не используйте конфиденциальные данные для первичной проверки.
