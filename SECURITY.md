# Сообщения об уязвимостях

Для непубличного сообщения используйте **docflow.lite@gmail.com**, тема «DocFlow security». Сначала отправьте описание проблемы и версии без реальных клиентских данных, ключей и конфиденциальных файлов. Канал передачи дополнительных материалов согласуется отдельно.

Не создавайте публичный issue с действующими секретами или эксплойтом против чужих систем. Для воспроизведения используйте отдельный синтетический проект. Согласованного SLA и программы вознаграждений нет.

Проверяется текущая предварительная ветка 0.3; старые выпуски не получают обещания бессрочной поддержки. Исправление и версия публикации определяются по воспроизводимости и влиянию дефекта. Не заменяйте опубликованные бинарники молча.

Границы: приложение локальное, один оператор. SQLite, документы и резервные копии не шифруются; доступ к папкам контролируется средствами ОС. Политика доступа, резервирования и работы с реальными данными определяется пользователем/оператором. Подробнее: [ограничения](docs/LIMITATIONS.md).
