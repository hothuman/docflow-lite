# Поддержка DocFlow

Для ошибки программы откройте [обращение GitHub](https://github.com/hothuman/docflow-lite/issues/new/choose). Укажите версию, Windows, действие, ожидаемый и фактический результат. Приложите снимок с вымышленными данными и маленький обезличенный пример, если он нужен для воспроизведения.

Не публикуйте клиентскую базу, документы, адреса, телефоны, ключи и полный список переменных среды. BUILD-INFO и диагностические сообщения сначала просмотрите: локальные пути могут содержать имя пользователя. Для уязвимостей используйте [SECURITY.md](SECURITY.md).

Вопросы настройки: [Telegram](https://t.me/de1grace), [email](mailto:docflow.lite@gmail.com). Для первого обращения достаточно описания процесса и желаемого результата. Реальные файлы передаются только после согласования канала, прав и условий работы.

Бесплатная alpha не устанавливает гарантированный срок ответа. Объём и условия платной настройки согласуются отдельно. Перед обновлением и диагностикой сделайте резервную копию проекта.
