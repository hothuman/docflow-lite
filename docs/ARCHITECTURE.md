# Архитектура текущей версии

`data.py` читает CSV/XLSX в неизменяемую таблицу и сохраняет номера строк. `safety.py` ограничивает входной объём, проверяет архив Office и XML, запрещает внешние связи/активное содержимое и формирует безопасные имена файлов.

`templates.py` сначала проверяет пакет через python-docx. Переменные разрешаются только по регулярной грамматике имени. Движок объединяет текстовые фрагменты внутри абзаца, заменяет совпадения с конца и сохраняет оформление первого фрагмента переменной. В ZIP заменяются только document/header/footer XML; остальное содержимое не перепаковывается через модель форматирования python-docx. Извлечения архива на диск нет.

`validation.py` проверяет обязательность и ограниченный набор типов. `profile.py` читает и атомарно сохраняет JSON-настройки с путями, сопоставлением и правилами. Настройки содержат ссылки на шаблоны, а не копируют их: при переносе нужно переносить и DOCX/таблицу.

`batch.py` выполняет предварительную проверку, создаёт временную папку рядом с будущим результатом и обрабатывает записи. Если не удалось создать один документ записи, её частичный комплект удаляется. Ошибка записи на диск прекращает весь запуск; готовая папка публикуется переименованием только после формирования отчётов. Каждый запуск имеет отдельное имя. Абсолютной гарантии сохранности при сбое питания не заявляем.

`cli.py` и `gui.py` используют один движок. Генерация GUI выполняется в QThread. Предпросмотр — текст; он не является встроенным Word renderer. В программном коде нет сетевых клиентов или телеметрии. Кнопка открытия результатов использует стандартный файловый менеджер только по нажатию пользователя.

`site/dist/` — отдельный статический сайт. Встроенный пример содержит тексты, заранее полученные тем же движком, а не браузерный генератор DOCX. Формы загрузки и отправки нет: кнопки открывают Telegram или email, сообщение посетитель отправляет сам. Аналитика и база обращений на сайте не подключены. Платная настройка описана отдельно от бесплатной программы.


В 0.1.1 GUI передаёт в QThread снимок уже загруженных данных и шаблонов, чтобы генерация совпадала с предпросмотром. XLSX-диапазон определяется по физическим XML-ячейкам до обхода сетки. Используется _worksheet_path из закреплённой openpyxl 3.1.5; при обновлении этой библиотеки нужно проверить совместимость.
