# Аудит DocFlow Lite

Дата проверки 21 октября 2026. Проверена сохранённая версия 0.1.0 и подготовлена исправленная версия 0.1.1. Итог: рабочая локальная бета в Linux; публичный запуск и воронка продаж не завершены.

Проверка выполнялась заново по байтам сохранённого архива, а не по прежнему описанию. Это техническая перепроверка с новыми контрпримерами; внешняя сертификация безопасности не проводилась.

## Фактические проверки

Исходный архив: SHA256 `ea6754f682148f46bf62c3d3ae51a118d3ae6558c08cd329735725e8e0241a52`. Проверены CRC ZIP и SHA256 всех 73 файлов из манифеста. На начало аудита различий между этими файлами и рабочей папкой не было. Исходная версия сохранена отдельно и не заменена исправленной.

Старый набор: 60 тестов прошли за 31.59 с. Семь новых проверок старой версии завершились ошибками; результаты сохранены в XML. После исправлений и обновления зависимостей полный набор: **68 passed in 12.02s**. Восемь дополнительных тестов охватывают пять вариантов ошибочных размеров XLSX, соответствие результата предпросмотру, Git ignore и повторную упаковку ZIP.

Среда: Linux, CPython 3.12.14; python-docx 1.2.0, openpyxl 3.1.5, lxml 6.1.3, PySide6-Essentials/shiboken6 6.10.2, pytest 9.0.3. Это не проверка запуска на Windows.

Дополнительно lxml закреплён на проверенной 6.1.3 вместо диапазона, разрешавшего более старые версии. Qt обновлён до 6.10.2, в котором исправлена CVE-2025-14576 компонента VectorImage. Приложение использует Qt Widgets и не загружает пользовательский SVG через этот компонент; эксплуатация этой уязвимости в приложении не показана. Текст QLabel явно отображается как PlainText. Обработка отсутствующего демопрофиля выдаёт ошибку в интерфейсе.

## Безопасность и границы проверки

Проверены запрет выражений шаблонов и выполнения кода, DTD/XXE, внешних отношений Office, макросов/вложений, полей Word, неполных пакетов, опасных ZIP-путей, XML-контрольных символов и небезопасных имён Windows. Пользовательские значения вставляются как текст XML; повторной интерпретации переменных из значений нет. Сетевых клиентов и телеметрии в приложении не обнаружено.

В исходных текстах выполнен поиск паттернов GitHub/OpenAI токенов, закрытых ключей и известного личного контакта основателя; совпадений не обнаружено. Данные примера вымышлены. Такая проверка не доказывает отсутствие любых секретов или уязвимостей. Архив с виртуальным окружением, токенами доступа или рабочими пользовательскими документами не формировался.

PyPI-аудит не покрывает автоматически все C++ библиотеки внутри Qt/libxml2. Для будущего EXE нужно отдельно проверить комплект динамических библиотек, notices и условия их распространения. Тексты лицензий Qt отсутствуют в найденных wheel-файлах; это отмечено в metadata и не выдано за готовность бинарного релиза. Собственная лицензия публичного исходного кода ещё не утверждена.

Предпросмотр текстовый. Нет циклов, условий, повторяемых строк, вставки изображений по переменной, OCR, электронной подписи и облачного кабинета. Нагрузочный прогон генерации 5000 комплектов и произвольные клиентские шаблоны не проверены. Действуют ограничения, описанные в README.

## Windows и GitHub

В сохранённом проекте EXE не найден. В этой Linux-сессии Windows-сборка не создана и не запущена. Есть BAT для запуска исходников, PowerShell-рецепт PyInstaller и ручной GitHub workflow проверки, но их наличие не является результатом выполнения на Windows.

В локальном проекте нет .git и remote. Подключение GitHub вернуло пустой список доступных репозиториев. Проверены структура исходников и README, но удалённые коммиты и состояние какого-либо недоступного репозитория проверить нельзя. Подтверждённой ссылки на GitHub DocFlow Lite нет.

## Публикации и монетизация

В доступном аккаунте Sites не найден проект с названием/slug DocFlow Lite; в hosting.json отсутствует project_id. Публичная публикация и рабочий внешний URL не подтверждены. Внутренний предпросмотр не является доступным клиентам сайтом. В HTML сохранён noindex,nofollow; публичный URL, canonical и sitemap ещё не настроены.

Созданы две версии ролика, реальные изображения интерфейса, скриншоты сайта, встроенный демопример и текст первой публикации. В тексте публикации остаётся место для фактической ссылки. Подтверждений размещения ролика/поста в социальных сетях нет. В исходниках нет ссылок или конфигурации этих каналов; аккаунты и рекламные кабинеты не названы, их состояние не проверено. Счётчики и сбор аналитики отсутствуют.

Воронка сейчас: публичное обнаружение не обеспечено; локальная демонстрация и скачивание подготовлены; канал обращения не подключён; согласование и оплата на сайте отсутствуют. Форма сохраняет запрос у посетителя и не создаёт лид у нас. Подтверждённых обращений или оплат по результатам этой работы нет; просмотры, конверсии и выручка не измерены.

## Что требует участия основателя

Нужен контакт для заявок, который можно разместить на сайте; сведения об исполнителе для условий и конфиденциальности; проверка демо на Windows 11. Перед публикацией требуется согласование по исходному брифу. Если GitHub-репозиторий создан вручную вне этой работы, нужна его ссылка или доступ.

Главный барьер первой продажи: посетитель пока не может найти опубликованную страницу и отправить нам обращение. Следующее практическое действие — выбрать контакт для заявки, подключить его к готовой странице и после согласования открыть публичный доступ. Проверка Windows и подготовка EXE остаются отдельным техническим ограничением демо.

## Передача результатов

Подготовлены отдельные архивы исходников 0.1.1, сайта, примеров, медиа и доказательств аудита. Общий архив включает эти материалы и неизменённые результаты версии 0.1.0. Windows EXE и подтверждённые публичные URL отсутствуют; фиктивные файлы для них не создавались.

Сам файл демо-ZIP проверен на целостность, уникальность записей и запуск после распаковки: 4 DOCX, 2 успешные записи, 1 пропущена. В приложении из отдельного демо-архива проходят 67 тестов; 1 тест сборки полного выпуска пропущен, поскольку архив демо не содержит исходников сайта и упаковщика полного проекта. Полный исходный проект проходит все 68 тестов.

Автоматическое скачивание ZIP нажатием кнопки сайта подтвердить не удалось: ожидание события и специализированное получение ссылки закончились тайм-аутом. Проверка внутреннего журнала Chrome была запрещена политикой URL браузерной среды. Отдельный HTTP-запрос из основной среды также не получил ответ. Это ограничение проверки; успешная доставка ZIP через сайт не заявляется. Перед публикацией нужно проверить скачивание в обычном браузере по фактическому внешнему URL. Здесь файлы переданы отдельными скачиваемыми вложениями.
