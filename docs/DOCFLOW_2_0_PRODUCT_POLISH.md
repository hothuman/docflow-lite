# DocFlow 2.0 · Stage 14 · Product Polish

Предварительная версия для приёмки владельцем — `2.0.0b1`. Публичную стабильную Windows Portable 1.0.1 можно скачать по прежней ссылке из README.

## Интерфейс

- «Документы» и «Мастерская» сохраняют общий каркас A+B+C. Пункт «Начало» ведёт к первой странице Core. Учебный пример показывает весь маршрут из таблицы в Word.
- На проверке два счётчика. Строки с ошибками выделены отдельно и будут пропущены при создании. Каждое замечание по-прежнему ведёт к соответствующей ячейке.
- В широком журнале карточку выбранного ремонта открывает кнопка справа или Enter в таблице. В компактном журнале кнопка рядом с «Новый ремонт». Сброс появляется при активном фильтре и возвращает фокус к поиску.
- В карточке ремонта действия с правками видны на вкладке документов, когда есть несохранённые изменения. Черновик DOCX открывается явно. Светлая область показывает подставленный текст. Вёрстку и печать проверяют в редакторе.
- Заголовки таблиц используют общую плотность и контраст. Сообщения об операциях в Мастерской используют цвета и отступы общей темы. Полный текст сообщения доступен в подсказке.

## Версия и проверка

Единственный редактируемый номер версии хранится в `src/docflow/__init__.py`. Из него берут версию Python-пакет, окно, журнал диагностики, отчёты, README сборки, SBOM и имя Portable. `BUILD-INFO.json` рядом с EXE и в комплекте совпадает и содержит стадию, коммит и SHA256 EXE. Форматы Core JSON v1 и SQLite schema 6 имеют собственные версии.

Windows CI сравнивает обычный запуск с проверенным по SHA256 публичным Portable 1.0.1. Лимит CI сохраняется. При долгом тесте журнал содержит текущее имя и стеки Python. Таймаут Stage 13 сам по себе не указывает конкретный тест. В отдельной проверке обнаружена задержка с ожиданием через `QTest.qWait`, поэтому вспомогательные сценарии обрабатывают события Qt с короткой паузой Python.

Документная генерация, финансовые расчёты, хранение проектов и условия распространения содержатся в действующих компонентах. Приёмка включает исходники и точный архив, старый профиль, рабочую копию проекта 1.0.1 и отдельное восстановление ZIP. Для предварительной сборки используйте копии проектов и отдельные настройки. Word, печать, Narrator и работа сотрудников подтверждаются собственными проверками.
