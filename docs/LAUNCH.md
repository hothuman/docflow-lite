# Публикация DocFlow

Основной сайт: https://docflow-lite.pages.dev/
Репозиторий: https://github.com/hothuman/docflow-lite
Выпуски: https://github.com/hothuman/docflow-lite/releases

Текущий этап — публичная предварительная 0.3.0a6. Факт публикации и точный состав определяются страницей Releases и манифестом соответствующего выпуска, а не названием локальной папки.

Программа и сайт выпускаются последовательно: проверенный prerelease с файлами → проверка реальных загрузок/SHA → сборка сайта с новой ссылкой → Direct Upload в существующий Cloudflare Pages docflow-lite → проверка production.

Cloudflare-проект использует Direct Upload и не публикует обычный push автоматически. Исторический workflow GitHub Pages заменён подготовкой preview-архива без deployment.

Контакты: https://t.me/de1grace и docflow.lite@gmail.com. Форма, аналитика, платежи и индексация выключены. Сбор данных и юридические проекты PR №4 не считаются утверждёнными публикацией приложения.

Подробности: [порядок выпуска](OFFICIAL_RELEASE.md), [Cloudflare](../site/docs/CLOUDFLARE_PAGES.md), [текущее выполнение](service/39_PUBLIC_PRODUCT.md).
