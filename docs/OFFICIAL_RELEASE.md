## Точная база и Windows

Зафиксируйте полный commit и clean tree. scripts/install_build_python.ps1 получает официальный CPython 3.14.10 x64 NuGet с фиксированным SHA и проверяет Authenticode PSF, не меняя системный PATH/реестр. Windows build: scripts/build_windows.ps1, requirements/windows-x64.lock (хеши), PyInstaller onedir/изолированные DLL. Linux source QA отдельно остаётся Python 3.13.16; это не интерпретатор поставки.

Сохраните Portable/Source/ThirdParty-Sources, LICENSE/notices, SBOM.cdx.json, BUILD-INFO, SHA256SUMS и WINDOWS-CI-RESULTS. Source ZIP должен быть точным FILE_HASHES, Portable — BUNDLE-SHA256, без посторонних файлов. SBOM перечисляет реально собранные дистрибуции/уведомления, не удостоверяет отсутствие всех CVE. Исходники/лицензии должны соответствовать новым версиям Qt, старые архивы a6 не подменяются.

## Draft и stable

release_candidate.py verify --directory release проверяет состав и SHA. prepare_github_draft.py формирует только draft и требует точного target/notes. Для стабильного номера нужно **отдельное** --stable-approved после фактического решения владельца и GO/NO-GO; это не разрешение обходить приёмку. RC имеет prerelease=true; stable — false. Обычный push не публикует Release. Запрещены повторная загрузка поверх опубликованных файлов и маскировка нового EXE старым номером.

После разрешённого merge, если дерево изменилось, пересоберите из final main и повторите затронутые проверки. Новый tag соответствует ровно BUILD-INFO.commit. До финального подтверждения владельца stable публично не выпускается.

## Сайт и Cloudflare

build_release_site.py активирует загрузку только после проверки реального опубликованного exact release, стадии, immutable=true для 1.0/RC, tag target, размера и скачанных SHA всех обязательных файлов. Поддерживаемая разметка версии проверяется тестами; неизвестная версия требует review. Offline browser fixture помечена synthetic_acceptance_fixture и **никогда не размещается**. Публикационный архив строится отдельно по реальному манифесту.

Существующий Cloudflare Pages docflow-lite сохраняется. Для текущего статического сайта размещение разрешено 26.10; коммерческий правовой GO остаётся отдельным. Для будущих изменений сверить применимые условия и разрешение. Формы/платежи/аналитика/индексация выключены; контакты не объявляются автоматически локализованным маршрутом. После deployment: HTTPS/страницы/404/заголовки/ресурсы/8 ширин/реальная загрузка/хеши. Предыдущий deployment и архив сохранить для отката.
