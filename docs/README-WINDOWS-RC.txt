DocFlow Lite 0.2.0rc1 — кандидат на выпуск

Подготовленная версия для проверки, не объявленная стабильным коммерческим релизом.
Требуемая платформа: Windows 10/11 x64. Фактическая автоматизированная проверка
выполняется на Windows Server 2022 в GitHub Actions; личная Windows 10/11 — отдельно.

1. Распакуйте ВЕСЬ portable ZIP в отдельную доступную для записи папку.
2. Сохраните _internal рядом с DocFlow-Lite.exe. Установка Python не нужна.
3. Запустите DocFlow-Lite.exe. Программа не имеет цифровой подписи.
4. Нажмите «Открыть демопример». Все данные примера вымышлены.
5. Просмотрите вкладки «Данные» и «Предпросмотр», затем «Поля и проверки».
6. Выберите папку результата и нажмите «Сгенерировать документы».
7. Две корректные записи дадут 4 DOCX, третья будет пропущена с двумя ошибками.
8. В разделе «Результат» откройте папку. Проверьте DOCX в Word или LibreOffice.
   report.json и report.csv содержат фактический отчёт по записям.

Свои файлы: XLSX/CSV с заголовками и DOCX с простыми переменными {{поле}}.
В «Шаблоны» можно исключить шаблон из комплекта галочкой, не удаляя исходный файл.
Для каждого поля выберите столбец, обязательность и правило проверки.
JSON-профили формата version=1 сохраняются и открываются в «Поля и проверки».
После изменения файлов на диске перечитайте их: генерация использует загруженный
снимок, чтобы неожиданные внешние изменения не подменили результат.

Ограничения: 5000 записей, 100 столбцов, 20 шаблонов. Только DOCX, не PDF.
Формулы Excel, макросы, внешние связи Office, OLE, циклы и сложные поля Word
не поддерживаются. Текстовый предпросмотр не воспроизводит вёрстку Word.
История между запусками и отмена незавершённого пакета не добавлены.
При обработке дождитесь завершения перед закрытием окна.
На малом окне/большом DPI используйте прокрутку; боковая панель становится компактной.

Нет аналитики, телеметрии и облачной обработки. Программа не шифрует результаты.
Исходные файлы не перезаписываются, каждый пакет получает отдельную папку.
Portable — папка программы, а не единый EXE. Не переносите EXE отдельно от _internal.
Лицензии зависимостей находятся в комплекте. SHA256 — в BUNDLE-SHA256.json и SHA256SUMS.txt.
