DocFlow Lite 1.0.1rc7 — Документы + Мастерская, приватный кандидат Stage4

Кандидат стабильной версии. Это ещё не стабильный выпуск.
Перед запуском прочитайте LICENSE.txt; программа бесплатна по условиям поставки.
© 2026 Гапоненко Ростислав Дмитриевич. Сторонние лицензии сохраняются.
Windows 10 x64 (1809+) / Windows 11 x64. Python устанавливать не требуется.

Распакуйте весь Portable ZIP. Запустите DocFlow-Lite.exe; сохраните _internal рядом.
При первом запуске может появиться предупреждение Windows о неподписанном EXE.
Цифровая подпись и проверка SmartScreen на вашем компьютере не подтверждены;
не отключайте защиту системы. Сверьте SHA256 и происхождение файла.

Документы: Таблица → Шаблоны → Проверка → Создание. Начните с «Открыть демопример»
или «Выбрать таблицу». Проверка всех строк выполняется перед генерацией; ошибки
и созданные файлы показаны в результате. Связанные поля ещё не означают проверку данных.
Мастерская: нажмите большую кнопку «Мастерская» сверху. База создаётся отдельно от EXE:
%LOCALAPPDATA%\DocFlowLite\Service\service.db
Один пользователь, локальный диск. Сетевые папки и одновременная работа не поддержаны.

Начните с Настройки → отдельное синтетическое демо либо откройте папку проекта
из Service-Synthetic-Demo.zip. Это вымышленные записи, не заказ и не оплата.
Нажмите «Новый ремонт»: аппарат «Из списка» сохраняет историю, «Новый аппарат»
создаёт отдельную запись. Для нового аппарата выберите собственника или нового клиента.
Проверьте сводку до «Принять в ремонт». Другой заказчик обращения не меняет собственника.
Карточка: Приёмка → Диагностика → Смета → Работы → Выдача. Переход между этапами
сам по себе не меняет статус. Сохранение и Ctrl+S доступны отдельно от выдачи и оплаты.
Редкие расходы, история статусов и файлы раскрываются по необходимости.
«Сформировать акт» создаёт новую версию. Настройте реальные сведения исполнителя
через «Настроить организацию»; старые DOCX/версии смет сохраняют прежние данные.
Незаполненный встроенный профиль явно обозначает нейтральную форму. Фирменный
шаблон с неполными сведениями не формируется. Word/ONLYOFFICE печатают через Ctrl+P;
программа не подтверждает факт печати. В истории сравниваются 2–6 выбранных ремонтов.

Резервирование: Настройки → Резервная копия, новое имя ZIP. Копия включает базу,
вложения, документы, пользовательские шаблоны и профили, не зашифрована. Храните отдельно и ограничьте доступ.
Восстановление всегда в новую папку; действующие данные не заменяются.
Перед внедрением проверьте восстановление и результаты в вашем Word/LibreOffice.
Не переносите автоматически сроки хранения данных исполнителя на базу мастерской.

Формы DOCX — нейтральные проекты без подписей и юридических обещаний.
Оригинальный сложный акт заказчика требует отдельного утверждения и адаптации.
Нет онлайн-кассы, эквайринга, ФНС, складских остатков, ролей или серверного режима.
Платежи в Service — только внутренние записи; деньги программа не перемещает.

Технический CI не заменяет ручную приёмку на личном Windows 10/11 и в Word.
Лицензии/исходные материалы Qt сохраняются в комплекте. Полная юридическая
сертификация LGPL/прав на собственный код не заявлена; вопросы PR №4 отдельны.

Интерфейс: единая тёмная концепция «Ночной инструмент», контекстная навигация,
обзор мастерской, паспорт ремонта, настройки и сохранение ширин колонок.
Поиск использует понятные поля записи; скрытые внутренние UUID исключены.
Подробные инструкции: docs/README.md и docs/UPDATE.md в исходниках.

Обновляйтесь в новую папку приложения. Перед первым запуском новой версии
сделайте копию проекта; проверьте её восстановление в отдельную папку.
Для отката верните прежнюю программу и сохранённую до обновления копию проекта.
Исторические изменения перечислены в CHANGELOG.md, не в инструкции запуска.

Генерацию Core можно отменить: дождитесь удаления временного пакета и повторите запуск. Предыдущие готовые результаты сохраняются. Повреждённую базу не исправляйте вручную; восстановите проверенный архив в новую папку.
