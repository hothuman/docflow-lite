DocFlow Lite 0.1.1 — Windows portable beta

Требования: Windows 10 (1809+) или Windows 11, x64. Python и Word для генерации не нужны.
Для просмотра DOCX используйте Word или LibreOffice. Интернет нужен только
для скачивания; генерация выполняется локально, без телеметрии.

1. Скачайте DocFlow-Lite-0.1.1-Windows-x64-Portable.zip из GitHub Release.
2. Полностью распакуйте ZIP в отдельную доступную для записи папку.
3. Сохраните рядом с EXE папку _internal и остальные файлы комплекта.
   Один EXE отдельно от комплекта не работает. Из окна ZIP не запускайте.
4. Запустите DocFlow-Lite.exe и нажмите «Открыть демопример».
5. Выберите доступную папку результата и «Создать пакет документов».

Ожидаемый результат: четыре DOCX, две обработанные записи, одна пропущенная.
В третьей записи намеренно не указана услуга и указана отрицательная сумма.
В папке результата появятся report.json и report.csv. Это две ошибки одной
записи. Готовые результаты проверьте перед использованием.

Редактируемые примеры находятся в examples/. Настройки сохраняются в JSON.
Текстовый предпросмотр не воспроизводит вёрстку Word. Условия, циклы,
вставка изображений по переменной и повторяемые строки не поддерживаются.
Не используйте конфиденциальные данные для первой проверки.

Проверки опубликованного комплекта описаны в WINDOWS-CI-RESULTS.json.
Автоматический запуск на Windows runner и ручная проверка Windows 10/11
разделены в отчёте. Файловые диалоги ОС и визуальная вёрстка в Word этим
автотестом не подтверждаются. Версия остаётся бетой.

EXE не подписан платным сертификатом. Windows может показать неизвестного
издателя. Проверяйте источник и SHA256; защиту Windows отключать не нужно.

Qt/PySide6 используются по LGPLv3. Лицензии и notices включены в licenses/,
QT-LGPL-NOTICE.txt и THIRD-PARTY-LICENSES.json. Соответствующие исходники Qt
и PySide6 находятся в отдельном ThirdParty-Sources ZIP того же релиза.
Сохраняйте исходники библиотек вместе с бинарной поставкой при её передаче.
Собственная открытая лицензия приложения этим файлом не вводится.

Воспроизведение сборки: Windows x64, CPython 3.13.16 x64; PowerShell:
  .\scripts\build_windows.ps1 -Python путь\к\python.exe
Скрипт устанавливает закреплённые колёса с проверкой SHA256, выполняет тесты,
собирает PyInstaller onedir, получает проверенные исходники библиотек,
создаёт ZIP, распаковывает его и дважды запускает собранный EXE.
Процедура воспроизводима; побайтовая идентичность разных сборок не заявлена.
