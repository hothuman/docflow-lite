# Service: ремонт за 5 минут

1. **Откройте проект.** Сверху должно быть его название. Если открытие отменено, выберите проект, создайте отдельный или восстановите копию. Пустые списки без открытого проекта не говорят о пропаже данных.
2. **Новый ремонт.** Для известного аппарата выберите его постоянный номер. Для нового явно включите «Новый аппарат», укажите номер, модель и клиента. Номер ремонта назначится автоматически; ручной ввод раскрывается отдельно. «Другой заказчик» относится к этому ремонту и не меняет владельца аппарата.
3. **Диагностика и смета.** Запишите причину и план, откройте Смету, сохраните расчёт и версию. Ответ заказчика отмечается вручную только по факту. Переходы между этапами не удаляют введённый текст. Ctrl+S сохраняет карточку.
4. **Работы и акт.** Внесите выполненные позиции, запчасти, фото. Нажмите «Сформировать акт». Excel не нужен. Откройте документ в установленном редакторе и используйте его печать. Повторное формирование оставляет предыдущую версию.
5. **Расчёты и выдача.** Отметьте фактическую оплату либо возврат. Неизвестное не равно нулю или долгу. Выдачу подтвердите отдельно. «История аппарата» показывает все обращения; «Найти оборудование / ремонт» ищет по деловым данным, архив включается явно.

Резервирование, восстановление, импорт и диагностика находятся в Настройках. Перед обновлением сохраните копию проекта. Реальные документы и персональные данные в публичную поддержку не отправляйте.
