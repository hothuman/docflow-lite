# Происхождение визуальных материалов

Знак d/ и палитра «Ночной инструмент» — существующая утверждённая система проекта. repository-cover.svg и social-preview.svg созданы кодом из этой системы; PNG отрендерены через Qt. Они иллюстрируют маршрут продукта и не выдаются за снимки интерфейса.

Текст в растровых обложках отрисован установленным Segoe UI; файлы этого шрифта в поставку не копируются. Настоящие экраны Core/Service получены на синтетических данных и обозначены отдельно.

В PDF услуг встроен поднабор Carlito из официального MSI LibreOffice 26.8.1 с действительной подписью The Document Foundation. Авторское уведомление и ссылка SIL Open Font License сохранены в FONT-NOTICE.txt. Отдельный TTF с приложением не распространяется.

Демонстрационные таблицы, документы, изображения и видео — вымышленные проверочные материалы. Клиентские логотипы, отзывы и данные не добавлены.
