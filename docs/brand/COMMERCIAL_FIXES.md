## Поток

Демо → выбор услуги → состав результата → подготовленное обращение → обсуждение и согласование индивидуального заказа. До выбора услуги не требуется ни установка программы, ни передача клиентского файла. Бесплатная самостоятельная ветка остаётся доступной.

Hash содержит только одно из публичных обозначений request-one/request-bundle/request-service. Нет формы, ввода, backend, fetch, localStorage, cookies, отправки email или сообщения Telegram. Копирование — явное действие с фиксированным текстом. При невозможности копирования видимый текст выделяется для ручного переноса. Выбор пакета не даёт согласия на обработку данных и не оформляет заказ.

## Сохранение юридического содержания

ASSET_PROVENANCE.json сохраняет прежние хеши исходных юридических блоков. legal_factual_update содержит точный до/после каждого разрешённого фактического изменения и текущий SHA. Регрессия обращает только этот delta и требует прежнего полного хеша. Условия программы software/лицензия, правообладатель и остальные положения не переписаны. Политика и условия услуг остаются проектами; инструкция на исправление достоверности не является их утверждением.

## Проверки

Содержательные регрессии проверяют согласованность каждого подготовленного письма и видимого текста, тариф/получателя, доступ без JS, hash/reload/Back, настоящую Clipboard API, отказ/отсутствие API и запоздалый результат прежнего пакета. Существующие проверки демо, галереи, 8страниц/15ширин, ошибок/ресурсов, noindex/CSP, ссылок загрузки, fallback-шрифта и доступности сохранены. Итоговые результаты относятся к конечному SHA в комплекте передачи, не к историческому прогону.

Приложение и бизнес-логика, main, стабильные релизы и production не меняются. Новый Direct Upload — только комплект на согласование; публикация не выполняется. Окончательные решения до платного запуска находятся в отдельном списке.
