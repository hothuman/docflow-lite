# Stage2 — приёмка владельцем

Сохраните копию проекта, распакуйте новый Portable отдельно. Строка проекта должна показывать действующий проект; отмена/ошибка открытия не сбрасывает A (rc4).

1. Пустой учебный проект: Новый ремонт, явно Новый аппарат/Новый клиент, имя, постоянный номер, модель, жалоба → Принять. Открывается карточка с отдельным № ремонта.
2. Поиск по аппарату → история → новое обращение. Два ремонта, один аппарат; прежние документы/владелец не переписаны.
3. Смета → редактировать расчёт → версия → фактическая ручная отметка ответа. Проверьте итог и неизменность предыдущей версии. Перейдите между этапами с несохранённым текстом, затем сохраните Ctrl+S.
4. Работы/запчасти/фото → Сформировать акт. Excel не требуется. Откройте документ в установленном редакторе; при его отсутствии остаётся файл и объяснение. Повтор создаёт новую версию.
5. Учтите оплату/возврат только по факту. Выдать требует подтверждения; неизвестные расчёты не становятся нулевыми. История аппарата доступна из карточки. Проверьте поиск старого номера и архив.
6. Проверьте560×420,820×620,1060×740 и100/125/150/200%: действия доступны, строки читаемы, Tab/Enter/Escape работают, несохранённый текст не пропадает. Восстановите backup в новую папку.

Сообщите результат пяти сценариев и конкретные трудности без клиентских файлов. До этой проверки READY FOR USER QA. Это не автоматическая приёмка Word/принтера. Этап3 не начат.
