# Stage2 — реализуемая структура

Сохраняется фактический Ночной инструмент: хвойный фон, лаймовый основной акцент, янтарный фокус. Упоминание винной палитры в промпте исторически неточно: утверждённая система docs/service/35_NIGHT_INSTRUMENT.md имеет приоритет как существующий бренд.

Обзор: Новый ремонт / Найти оборудование или ремонт / Продолжить работу / Документы; три подтверждённых показателя и последние обращения. Пустой проект объясняет начало. Импорт, backup, диагностика — настройки. Без открытого проекта — состояния и восстановление rc4.

Карточка: номер ремонта, аппарат/клиент/дата, явный статус, отдельно финансы. Пять этапов: Приёмка, Диагностика, Смета/согласование, Работы, Выдача/документы. Вложенные разделы сохраняют запчасти, расходы, оплаты, фото и версии; исходник и смена номера — меню Ещё. Никаких автоматических выводов об оплате/согласовании. Исторические записи допускают нелинейную работу.

Новая приёмка: явно новый/существующий аппарат и клиент; обязательные поля отмечены. Одна транзакция без изменения схемы. Номер ремонта автоматически, ручной ввод раскрывается. Повтор использует ID выбранного аппарата, не модель. Поиск общий, архив включается явно.

Иконки собственного QPainter-набора: лист/документ, люди, ₽, инструмент, часы, поиск; русские подписи всегда. Tab/Enter/Escape, Ctrl+S карточки, предупреждение несохранённых правок. Видимость критичных действий проверяется геометрией, деньги не скрываются. Типовые размеры560×420,820×620,1060×740 и DPI100–200.
