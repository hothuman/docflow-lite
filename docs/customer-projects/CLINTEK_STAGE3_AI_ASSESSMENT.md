# 3C — PROTOTYPE / NOT_APPROVED_FOR_DELIVERY

В клиентском EXE нет помощника/модели/API. experiments/repair_text_parser.py — отдельный stdlib CLI для синтетики, исключён из PyInstaller; он не импортирует приложение, БД и сеть, не записывает файлы. Исходник прототипа доступен отдельно для рассмотрения, не как функция Service.

| Вариант | Предсказуемость / ресурсы | Ограничения |
|---|---|---|
| Детерминированный разбор | Нет весов/дополнительных зависимостей; bounded5000знаков/30строк | Только явные метки Жалоба/Диагностика/План; свободный рассказ не понимает |
| Опциональная локальная LLM | Может предлагать поля из свободного текста | Не выбрана/не загружена/не измерялась; RAM/VRAM/скорость зависят от модели и ПК, фиксированных обещаний нет; нужны лицензия, eval и безопасная обвязка |
| Внешняя модель | Технически возможна в будущем | Не разрешена: клиентские данные/инфраструктура/правовой маршрут/API-бюджет не согласованы |

Прототип возвращает предложение лишь трёх текстовых полей с исходной строкой и requires_human_confirmation. Неизвестные/повторные метки требуют проверки. Цена, количество, единица, дата, номер и статус не выводятся как поля и не меняются автоматически. Любые цифры внутри жалобы остаются буквальным текстом, не бухгалтерской командой. Это не ИИ и не готовая защита от всех атак.

Матрица tests/service/test_stage3_preferences.py: корректные3метки; отрицательные Цена/Дата/Статус; injection ignore/system; повторная Жалоба; переполнение. Нет тихого назначения числового поля. Дополнительные неподдерживаемые единицы/валюты/неверные поля требуют ручной проверки. Словарный фильтр injection ограничен: гарантией служит отсутствие действий/записи и полная изоляция, а не распознавание любого злого текста.

Будущий GO требует: отдельного решения о включении; согласованных целевых полей/языка/данных; корпуса обезличенных положительных и отрицательных кейсов; измерения precision/неизвестных/ложных сумм на реальном целевом ПК; resource budget; проверки прав модели; offline enforcement; только preview с явным утверждением/редактированием/отменой, журналом и отсутствием автономных финансовых/статусных операций. Голос, клиентские данные и облачные сервисы — отдельные решения. Нынешний результат не принят заказчиком и не входит в поставку программы.
