# Контракт тестовой выгрузки каталога

Это файловый обмен XLSX/CSV. Прямое подключение и обратная синхронизация с 1С не реализованы. Пример — examples/catalog/synthetic.csv, данные вымышлены. Реальная структура заказчика не подтверждена: READY_FOR_REAL_DATA_TEST.

Первая непустая строка содержит уникальные заголовки. Сопоставление выбирается вручную; совпадающие технические заголовки из примера предложены автоматически. Для XLSX выберите лист и перечитайте файл; для CSV — auto, utf-8-sig либо cp1251. Коды с ведущими нулями в XLSX должны храниться текстом: программа не может восстановить нули, уже потерянные экспортёром чисел. XLSX-формулы не вычисляются.

| Поле примера | Значение / правило |
|---|---|
| external_id | Устойчивый внешний ID, точное регистрозависимое сравнение |
| sku | Внутренний артикул, отдельный от внешнего ID, уникален внутри источника при наличии |
| name | Обязательное название, до500 знаков |
| group / subgroup / category | Текст ровно из выгрузки, без придуманной иерархии |
| kind | part=запчасть, work=работа; пустое требует выбора при вставке в смету |
| unit | Единица из выгрузки, пустая требует ручного подтверждения в смете |
| description / manufacturer | Необязательный безопасный текст |
| price / currency | Точные неотрицательные деньги до2 десятичных знаков; явная ISO-валюта, RUB для рубля; пустая цена не равна0 |
| availability / exported_at | Текст источника, без складской семантики и догадок о дате |
| shelf_raw | Сырой текст «полки», значение не интерпретируется |

Профиль хранит источник, карту полей, ключ external_id ИЛИ sku, лист/кодировку, явную резервную валюту и флаг обновления цен. Файловые пути не сохраняются в профиле. Источник — постоянная явная метка: изменение метки означает другой независимый справочник. Автоматического переноса ключей между источниками нет. Пробелы вокруг ID/артикула — ошибка, а не незаметная нормализация. 001, 1, ABC, abc — разные ключи. Сходство названий не означает совпадение.

Внутрифайловые повторы ключа/артикула и артикул другого внешнего ID конфликтуют. Исправьте выгрузку либо явно пропустите проблемные строки. Новые/обновляемые/неизменные строки видны до записи. По умолчанию цена существующей позиции сохраняется; обновление цены включается явно. Смена выбранного устойчивого поля/источника требует нового предпросмотра и внимания оператора. Отсутствующие в новом файле позиции не удаляются. При изменении каталога другим действием прежний preview отклоняется.

Лимиты: исходник5MiB; распакованный XLSX20MiB; 5000 строк,32 колонки,2000 знаков/ячейку,8MiB суммарного текста; разбор30сек; общий каталог50000 позиций. Поиск показывает первые500 совпадений: уточните строку поиска. Проверяются формулы, ссылки/UNC, управляющие символы, zip/XML-защиты Core. Сеть не используется. Разбор идёт в отдельном завершаемом процессе над копией байтов; отмена не меняет проект. Запись — одна транзакция, отчёт с SHA файла и политикой хранится в проекте. Исполнительный код/SQL из файла не запускается.

Каталог не склад: остатки/резерв/списание отсутствуют. Смета копирует подтверждённые название/тип/единицу/количество/рублёвую цену, описание и ссылку на происхождение снимка. Иностранная валюта не пересчитывается: цену в рублях вводит сотрудник. Пустая цена не подставляется как нулевая. Изменение каталога не изменяет черновик/зафиксированную версию/старый DOCX. Каталог и профили входят в резервную копию проекта; настройки экрана живут отдельно в пользовательском INI.
