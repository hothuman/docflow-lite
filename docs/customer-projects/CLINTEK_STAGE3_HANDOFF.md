# Единая приёмка Stage1–3 — rc6

Статус технического кандидата: READY FOR USER QA после свежих успешных CI/Portable-проверок. Stage1 rc4 владелец ранее проверил в Windows; Stage2/3 окончательно не приняты. Проверку Word rc1 из старого выпуска не переносим на rc6.

Распакуйте Portable целиком в короткую локальную папку, например C:\DocFlow-QA. Запустите DocFlow-Lite.exe. Сначала используйте отдельный учебный проект и examples/catalog/synthetic.csv. Не заменяйте рабочую v1.0.0 и не открывайте единственный оригинал старой базы. Для v4/v5 программа предложит отдельную обновлённую копию схемы6; сохраните оригинал и backup для отката. Старый EXE не открывает новую схему: откат — старый EXE + прежняя отдельная копия.

## Чек-лист владельца

- [ ] **Stage1 открытие:** выбор папки → отмена; приложение остаётся отзывчивым. Затем открыть/создать проект. Ошибочный путь → понятная ошибка → повтор успешен. Без проекта доступны открытие/восстановление, бизнес-формы не падают.
- [ ] **Stage1 история:** аппарат и обращение имеют разные номера. Изменение номера обращения не меняет номер аппарата. Повторный ремонт попадает в историю того же явно выбранного аппарата; сомнительные исторические строки сами не объединяются.
- [ ] **Stage1 документы/финансы:** неизвестная историческая стоимость/оплата не считается нулём или подтверждённым долгом; проверить реальные согласованные суммы, фото/подписи/акты по существующим правилам. Никакого автоматического согласования.
- [ ] **Stage2 пять шагов:** новый ремонт с новым клиентом/аппаратом → диагностика → предварительный расчёт/версия/ручная отметка → работы/оплата → выдача. Затем повторное обращение через историю и возврат без потери введённого текста.
- [ ] **Stage2 удобство:** найти аппарат/ремонт; документы доступны напрямую; ACT без Excel; ошибки и несохранённое состояние понятны. Проверить окно небольшого размера и125/150/200%, Tab/Shift+Tab/Enter/Space/видимый фокус.
- [ ] **Stage3A импорт:** Настройки → Каталог → Импорт; выбрать synthetic.csv, постоянный источник «Учебный», код external_id и name, остальные поля по примеру. Предпросмотр →1или2новых строки → подтвердить; повторить → без новых дублей. Сменитьлист/кодировку → перечитать → перепроверить.
- [ ] **Stage3A конфликты:** скопировать строку в учебном CSV, проверить конфликт до записи; отменить без изменений. Проверить явный skip только после осознанного решения. Прерывание чтения/записи оставляет проект целым.
- [ ] **Stage3A смета:** открыть ремонт → Смета → Редактировать расчёт → Из каталога → поиск по артикулу → выбрать/подтвердить количество/цену → сохранить расчёт → сохранить версию → DOCX. Новая цена источника с включённым обновлением не меняет прежнюю версию и файл.
- [ ] **Stage3B:** Настройки → Настроить стартовые действия → пресет/порядок/сохранить → перезапуск. Новый ремонт/Документы/Настройки доступны. Вернуть по умолчанию возвращает стандарт. Простой ремонт не требует настройки.
- [ ] **Backup/restore/upgrade:** учебная копия включает каталог, профиль, журнал, вложения и версии; восстановить в новой папке. Обновить отдельную копию проектаrc5 и проверить старые номера/суммы/документы. Исходную папку не менять.
- [ ] **Word/принтер:** открыть актуальные фирменные/учебные DOCX в Microsoft Word: длинные строки/таблицы/фотографии/подписи/переносы, распечатать тест. Эти проверки ещё не выполнены агентом.
- [ ] **Реальная 1С:** после разрешения на конкретный обезличенный экспорт согласовать ключи/тип/валюты/полки; сверить число позиций, суммы/профиль и повторный импорт в отдельном проекте. Пока READY_FOR_REAL_DATA_TEST.

3C не ищите в программе: только отдельный офлайн-прототип и assessment. Не передавайте клиенту как принятую функцию. После проверки верните: пункт, версия/масштаб Windows, ожидаемый/фактический результат, обезличенный скриншот. Не публикуйте базу, реквизиты, клиентские документы или ключи.
