# Проверка каталога Stage3

Все файлы синтетические. В репозитории нет выгрузки клиента. Тесты tests/service/test_stage3_catalog.py и test_stage3_routes.py воспроизводят:

- CSV UTF8-BOM/cp1251, XLSX с несколькими листами, точные нули/кириллица; неверную кодировку, формулы, ссылки, управляющие знаки, отрицательную/слишком точную цену, неявную валюту/тип.
- Preview без записи, явное подтверждение, ошибки и конфликты, явный skip, дубли ключа/артикула, stale-preview после конкурирующего изменения, atomic cancel с откатом уже вставленных строк.
- 2000позиций, повтор без дублей, неизменность отсутствующих позиций, отдельные001/1/ABC/abc, сохранение групп/полки. Лимит5001строки, размерафайла и принудительный timeout процесса.
- Цена неизвестна/ноль различаются; политика сохранения/обновления цены; цена сметы требует подтверждения.
- Snapshot → версия → DOCX; после повторного каталога SHA документа, payload и суммы прежней версии прежние. Backup/restore возвращает каталог, профиль, журнал и смету.
- Отдельная копия синтетической схемы5→6 сохраняет все строки старых таблиц и файлы; оригинал не изменён. Прежняя миграцияv4 и отмена открытия остаются в полной регрессии.

Native --stage3-self-test повторяет файловый разбор в замороженном процессе, реальные Qt preview/apply/replay/picker/черновик, сохранение версии/документа и восстановление. Эту же проверку включает строгий verifier Windows Portable на100/125/150/200%. Остальные проверки Stage1/2 не заменены.

Фактические свежие результаты хранятся в handoff REPORT.md, full-tests.xml и WINDOWS-CI-RESULTS.json; CI по точному SHA указан в Draft PR. Пустая строка checklist не означает выполненную ручную проверку. XLSX из настоящей 1С, Word, физический принтер и общая приёмка владельцем открыты.
