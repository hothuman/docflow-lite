# Интерфейс Stage3

Новая функция не обязательна в обычном ремонте. Путь каталога: Service → Настройки → Каталог из XLSX/CSV. В редакторе предварительного расчёта дополнительная кнопка «Из каталога». Четыре главных действия Stage2 и пятишаговая карточка сохраняются.

Импорт: выбратьфайл → прочитатьлист/кодировку → назватьисточник → сопоставитьназвание/код и остальныеполя → проверитьизменения → посмотретьпричины/конфликты → подтвердитьзапись. Изменение параметров инвалидирует прежний preview. Для листа/кодировки требуется перечитать файл. Диалог прогресса показывает отмену; разбор в отдельном процессе, запись атомарна. Поля/длинная форма прокручиваются, закрытие и действия доступны без растягивания всего окна.

Настройки → Настроить стартовые действия: проверенные пресеты, флажки штатных действий и порядок «Выше/Ниже», сохранение и сброс в одно действие. «Новый ремонт»/«Документы» обязательны; «Настройки» остаются в боковой навигации. Скриптов/кода/новых бизнес-команд нет. Scope: interface.ini текущего пользователя либо DOCFLOW_SETTINGS_DIR переносимой установки. Старая ширина колонок не изменяется, БД не участвует. Дефектный JSON → стандарт4действия, объяснение и reset в редакторе.

Автоматическая проверка: реальные Qt маршруты, изменение пресета/повторное создание панели/reset, damaged/unhashable/unknown настройки, сохранение прежних INI-ключей; каталоги560×420/820×620/1060×740, кнопка закрытия в пределах окна. Native эти3размера на100/125/150/200%. Полная прежняя матрица Core/Service/Stage2 остаётся в CI. Снимки получаются из работающего приложения, не макеты.

При native проверке первого кандидата обнаружен минимальный размер, мешавший окну560×420. Исправление: общая прокрутка страницы импорта вместо конкурирующих минимальных высот формы/preview; строгий assert размера сохранён, добавлена проверка доступности кнопки применения после прокрутки. Enter/двойной щелчок раскрывает все переносимые значения до записи, вкладка отчётов восстанавливает последние20 импортов из БД. Профиль загружается и до выбора файла, включая пользовательские заголовки и лист.

Ручная приёмка отдельно: Tab/Shift+Tab, Enter/Space, видимость фокуса, длинные русские названия, диалог выбора реального листа/кода, доступ к финансовым сведениям, удобство исходных пятишаговых сценариев. Автоматический Tab order не доказывает человеческую интуитивность. Единый чек-лист — HANDOFF.
