## Перед первым платным заказом

1. Владелец подтверждает исполнителя/оператора, ФИО и необходимый контакт для обращений; ИНН и банковские реквизиты передаёт конкретному заказчику приватно. Заполненные документы не коммитить.
2. Локально проверяет действующий НПД, ограничения режима и фактический банковский тариф. Нет подтверждения счёта/тарифа — нет утверждения о готовом приёме оплаты.
3. Проверяет именно поданное уведомление и квитанцию РКН, а не только код сформированной формы. Ожидание записи в реестре само по себе не заменяет проверку надлежащего уведомления.
4. Закрывает [карту обработки](02_Data_Processing_Map.md): страна и база первичного сбора, реальные получатели, переписка, рабочая папка, резервные копии, сроки и ручное удаление. Telegram/Gmail/Cloudflare не объявлены соответствующими 152-ФЗ по умолчанию.
5. Сверяет актуальную ст. 12 и утверждает документированный вывод по каждому трансграничному маршруту. При необходимости отдельно подаёт соответствующее уведомление лично; обычное уведомление оператора его не заменяет.
6. Утверждает проекты и заключает конкретный [заказ](../../sales/05_Individual_Order_and_Acceptance.md) с согласованными результатом, ценой, сроком, оплатой и приёмкой.

До этого возможна подготовка на вымышленных данных; даже идентификатор собеседника в переписке может быть персональными данными — отсутствие вложений не является освобождением от закона.
