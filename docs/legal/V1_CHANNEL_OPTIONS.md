# Выбор первичного канала обращений

Проверено 26.10.2026. По ответу владельца отдельного подтверждённого канала в РФ пока нет. Ничего не зарегистрировано и не оплачено. Выбор сервиса сам по себе не закрывает весь правовой GO.

Рекомендация — сначала рассмотреть вариант «для команды» с явным поручением, без CRM, формы и рассылок. Точная цена и покупка требуют решения владельца; наличие одного пользователя и домена пока не подтверждено. Аккаунт оформляется самим владельцем, пароль/коды не передаются в чат.

## Настройка после решения

1. Сохранить конкретные действующие условия и подтверждение региона для выбранной услуги, перечень получателей/копий/логов и порядок удаления. Отдельно оценить обработку регистрационных данных владельца.
2. Включить второй фактор, проверить восстановление и список активных сессий; отключить внешнюю переадресацию, зарубежные интеграции и ненужные приложения. SPF/DKIM/DMARC — если свой домен.
3. Первые материалы — полностью вымышленные. Адрес корреспондента всё равно может быть ПД. Реальные документы третьих лиц принимать только после отдельной проверки основания/поручения.
4. Обновить карту данных, политику и уведомление РКН по фактическому маршруту. Согласовать сроки хранения и удаления отдельно для заявок, рабочих файлов, копий, договора и налогового архива.
5. Проверить отправку/фактическое получение одного синтетического обращения, ответ владельцем, удаление из inbox/корзины/локальной копии и ограничения удаления у провайдера. Новая отправка без поручения не выполняется.
6. Заменить контакт согласованно в сайте, PDF, README, инструкции и шаблоне заказа; выполнить проверку ссылок/браузера. Gmail не делать автоматической копией нового ящика.

## Отдельный вопрос Cloudflare

У текущего Pages обнаружены NEL/Report-To; провайдер обрабатывает сетевые запросы даже без формы. Выбор почты не устраняет эту цепочку. До коммерческого GO нужны оценка роли/мест/получателей/уведомлений и решение владельца по публичной витрине. Новый хостинг не создавался; production не менялся. Нет основания обещать отсутствие трансграничной обработки.
