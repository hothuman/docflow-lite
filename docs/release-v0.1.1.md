DocFlow Lite v0.1.1 — первая portable-бета для Windows x64.

Распакуйте **Windows-x64-Portable.zip целиком** и запустите DocFlow-Lite.exe.
Python устанавливать не требуется. Сохраните папку `_internal` рядом с EXE.
Кнопка «Открыть демопример» загружает таблицу и два DOCX-шаблона. Ожидаются
четыре DOCX, две обработанные записи и одна пропущенная запись с двумя ошибками.

Перед публикацией workflow выполняет тесты исходников, извлекает portable ZIP
в путь с кириллицей/пробелами и дважды запускает настоящий собранный EXE на
Windows runner без Python в PATH. Фактические результаты — в
`WINDOWS-CI-RESULTS.json`, среда и коммит — в `BUILD-INFO.json`.

**Границы:** это автоматическая проверка CI. Ручная проверка на пользовательских
Windows 10/11, системных файловых диалогов и визуальной вёрстки DOCX в Word
не подтверждена. EXE не подписан сертификатом. Версия не объявляется стабильной.

Вложения: portable ZIP, исходники проекта, соответствующие исходники
Qt/PySide6, инструкция и SHA256. Лицензии библиотек включены в portable.
Открытая лицензия самого DocFlow Lite не добавлялась.
