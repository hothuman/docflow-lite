# DocFlow 0.3.0a6 — предварительный выпуск

Новая версия объединяет Core / Lite и Service alpha в приложении с тёмной концепцией «Ночной инструмент». Это публичная alpha для знакомства и обратной связи, не заявление стабильности и не приёмка клиентского внедрения.

## Изменения

- Единая тёмная тема программы: хвойные поверхности, лаймовое основное действие, янтарный фокус и читаемые статусы.
- Явное переключение Core/Service, контекстная навигация с текстовыми подписями, последовательность подготовки документов.
- Паспорт ремонта разделяет номер аппарата и обращения; подсказки показывают фактическое состояние. История открывается без изменения обращения.
- Длинные действия Core переносятся в компактном окне. Сохранены базы, профили, шаблоны и документы.
- Исправлена изоляция DLL при упаковке Windows: исключено попадание чужого ICU из сторонних инструментов, вызывавшее ошибку импорта QtCore.
- Новый сайт с настоящими экранами Core/Service, мобильной навигацией и точным разделением бесплатной программы и услуг настройки. Его размещение — отдельный шаг после публикации файлов.

## Скачать и запустить

В опубликованном выпуске выберите `DocFlow-Lite-0.3.0a6-Windows-x64-Portable.zip`, сравните SHA256 с прилагаемым манифестом, распакуйте весь ZIP в отдельную папку и запустите `DocFlow-Lite/DocFlow-Lite.exe`. Windows 10 1809+ / 11 x64, Python не нужен. `_internal` должен оставаться рядом с EXE.

Перед открытием существующего проекта сделайте резервную копию и проверьте восстановление в отдельной папке. Новую программу не распаковывайте поверх рабочей. Для возврата используйте прежнюю программу и копию проекта, сделанную до обновления.

## Проверено

Для базы приложения `0d4fd5e3ad1cfed74f4dbaaa11d0239f1a254168`: 260 тестов +16 подтестов, Windows/Linux CI, браузерный CI, 150 проверок размеров Core и 450 Service, отдельная проверка frozen EXE, генерация Core/Service, резервирование/восстановление. Конкретные происхождение и SHA выбранной поставки указаны в BUILD-INFO.json и SHA256SUMS.txt. Не смешивайте локальную Portable Python 3.12.10 и CI Python 3.13.16.

## Известные ограничения

EXE не подписан. SmartScreen и отсутствие предупреждений Windows не гарантируются. Service рассчитана на одного оператора и локальную SQLite; нет синхронизации, банковских/кассовых интеграций. Финансовые записи и согласования отмечаются вручную. Данные и копии не шифруются.

Визуальная приёмка всех документов в Microsoft Word, приёмка a6 владельцем, реальные материалы и формы заказчика пока не подтверждены. Поставляемые документы/демо содержат только вымышленные данные. Гарантийные и юридические формы остаются проектами; это не юридическая консультация и не утверждение договора.

Оригинальные права и лицензии сохранены. Условия сторонних библиотек, уведомления и соответствующие исходники поставляются отдельно. Новая открытая лицензия DocFlow этим выпуском не назначается.
