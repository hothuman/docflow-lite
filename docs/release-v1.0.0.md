# DocFlow Lite / Service 1.0.0

Первый стабильный выпуск универсального локального приложения Core + Service. Бесплатное личное и деловое использование — по LICENSE.txt, без назначения новой открытой лицензии оригинальному коду.

## Что входит

- Core: XLSX/CSV → DOCX-шаблоны → сопоставление/проверки → предпросмотр → комплект и отчёт; сохраняемые профили.
- Service: клиенты, оборудование, отдельные и повторные обращения, история, версии смет, ручные согласования, внутренние оплаты/возвраты, вложения, DOCX, импорт, резервные копии.
- Интерфейс «Ночной инструмент», отдельная навигация Core/Service, понятные основные действия.
- Отмена незавершённой генерации Core с сохранением старых результатов и повторным запуском.
- Проверка фактической схемы SQLite до восстановления/миграции и защита от неоднозначных Windows-путей.
- Точный состав Portable/исходников, SHA256, BUILD-INFO, SBOM, лицензии и соответствующие исходники библиотек.

## Запуск и обновление

Распакуйте весь Windows x64 Portable; _internal должен остаться рядом с EXE. Python не требуется. Начните с демо. Перед обновлением закройте программу, создайте и восстановите проверочную копию проекта в новую папку. Новый Portable распаковывайте отдельно; для отката храните прежнюю программу и копию до обновления.

## Ограничения

EXE NotSigned: подпись и отсутствие предупреждений SmartScreen не заявляются. Целевая среда Windows 10 1809+/11 x64; автоматические нативные проверки выполнены на Windows 11 и Windows Server 2022. Один оператор, локальная SQLite; файлы и копии не шифруются программой. Нет банка, кассы, облачного сервера и многопользовательской общей базы.

Core поддерживает простые переменные, не циклы/произвольные повторяемые строки/изображения по переменной. Service поддерживает объявленные строки и изображения, не любой сложный Word-шаблон. Юридическое содержание документов утверждает пользователь; гарантийный талон остаётся прототипом. Внутренние оплаты не являются переводом денег или кассовым чеком.

Коммерческие условия и маршрут обработки персональных данных ещё проверяются отдельно. Этот выпуск не объявляет полный коммерческий/юридический GO.
