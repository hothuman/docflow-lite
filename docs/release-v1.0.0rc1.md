# DocFlow 1.0.0rc1

Кандидат стабильной версии для проверки. **Не stable и не завершённый коммерческий запуск.**

- Отмена Core удаляет незавершённый пакет, сохраняет прежние результаты и позволяет повторить запуск.
- Restore проверяет структуру SQLite/защиту истории и совпадение версии манифеста. Валидные старые копии мигрируют только после проверки; исходный архив не меняется.
- Неоднозначные имена Windows и выход из проекта отвергаются.
- Поставка проверяет точный состав исходников/Portable, содержит SBOM и явную стадию. Stable требует отдельного подтверждения.
- CPython 3.14.10 x64, Qt/PySide6 6.12.0, setuptools 84.2.1; официальные источники и закреплённые хеши.

Здесь не утверждаются финальный CI/EXE, Word или приёмка владельцем: результаты привязаны к BUILD-INFO и отдельному отчёту QA кандидата. EXE не подписан до фактического изменения статуса. Один оператор/локальный диск, без шифрования, банка/кассы/сервера. Core — простые переменные; Service — объявленные поля/строки/изображения, не произвольный шаблонизатор.

Утверждённые права и бесплатность сохранены. Юридический PR4, реестр/уточнение РКН и маршрут ПД — отдельные незакрытые критерии коммерческого GO. Новые формы/платежи/аналитика/индексация не включены. Клиентская адаптация не выполнялась.
