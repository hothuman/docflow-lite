# DocFlow Lite 1.0.1

Статус — кандидат стабильного выпуска для проверки владельцем. Публичная версия на момент подготовки — [v1.0.0](https://github.com/hothuman/docflow-lite/releases/tag/v1.0.0).

## Что изменилось с 1.0.0

- **Документы.** Четыре шага от выбора XLSX/CSV до готовых DOCX. Автосопоставление, предварительная проверка, сохранённые профили и понятный результат пакетной генерации.
- **Мастерская.** Единое рабочее пространство с журналом, карточкой ремонта и историей оборудования. Отдельные заказчик и собственник, сравнение обращений, сохранённые версии смет, экспорт CSV и защита изменений стоимости после выдачи.
- **Импорт.** Локальные каталоги и история из XLSX/CSV с предварительной проверкой, явным сопоставлением и защитой от дублей. Неизвестные даты и суммы сохраняются без подстановки.
- **Проекты.** Безопасное открытие или восстановление в отдельную папку, повторное открытие последнего проекта и понятное поведение, когда проект занят. Резервный ZIP появляется под окончательным именем после проверки и атомарной публикации. Существующие копии защищены от перезаписи. Для старых схем используется отдельная копия. [Обновление и откат](UPDATE.md).
- **Печатные формы.** Предпросмотр актов и смет, диагностика шаблонов, фотографии в поддерживаемых формах. Ранее сформированные DOCX сохраняются.

## Ручная QA владельца

Результаты предоставлены владельцем для проверявшегося кандидата 1.0.1. Автоматические проверки интеграционного PR фиксируются отдельно.

| Сценарий | Статус |
| --- | --- |
| Запуск, открытие проекта, DOCX, Excel, валидация | PASS |
| Word Online, PDF | PASS |
| Системное масштабирование Windows 125%, 150%, 200% | NOT TESTED |
| Windows Narrator, физическая печать, настольный Microsoft Word | NOT TESTED |

**Windows EXE без цифровой подписи.** Сверьте SHA256 полученного Portable перед запуском.
