# DocFlow Lite 2.0.0rc1

Кандидат для финальной приёмки владельцем. Публичный стабильный выпуск — 1.0.1.

## Что проверять

- В «Документах» загрузите XLSX или CSV, проверьте поля Word, откройте замечание и создайте комплект. Светлая область показывает текст с подставленными значениями. Окончательную вёрстку проверяйте в готовом DOCX.
- В «Мастерской» откройте учебный проект или восстановите копию. Проверьте переход из журнала в карточку и обратно, повторный ремонт того же аппарата, смету, оплату и документ. Смена этапа в карточке сама по себе не меняет статус ремонта.
- При запуске 2.0.0rc1 прежний рабочий проект не подхватывается из настроек 1.0.1. Открывайте копию явно. [Инструкция обновления и отката](UPDATE-2.0.md)

Перечень улучшений — в [CHANGELOG](../../CHANGELOG.md). Версия, коммит и SHA256 EXE указаны в BUILD-INFO. Целостность перед запуском проверяется по контрольной сумме Portable из комплекта кандидата.

## Известные ограничения

- Windows x64 Portable. EXE без Authenticode-подписи. Отдельно проверьте предупреждения на своём Windows.
- Копии Service содержат пользовательские данные и не зашифрованы. Создавайте копии в отдельное место с ограниченным доступом. Совместное редактирование через сетевую папку не поддерживается.
- Платежи и возвраты в Мастерской — записи внутреннего учёта. Внешних платёжных операций нет.
- Текстовый предпросмотр показывает значения и порядок текста. Разбиение на страницы и печать длинных форм (QA‑03) требуют проверки в настольном Word.
- Фактический статус Narrator, системного DPI, переноса между мониторами, настольного Word и физической печати указан в чек-листе владельца. Автоматические проверки Qt охватывают раскладку, фокус и размеры элементов.
