# DocFlow Lite 2.0.0rc2

Кандидат Stage 15 для финальной ручной приёмки. [Переход и возврат](UPDATE-2.0.md) также описаны прямо в Portable в README-WINDOWS.txt.

- Технический журнал сохраняет версию, тип ошибки, фиксированный код операции и до шести мест в коде приложения. Текст исключений, пути, цепочки исключений и данные проекта исключены. Два источника событий используют один ротируемый журнал. Старые файлы diagnostic.log могут содержать рабочие данные и остаются на диске отдельно.
- Стабильная 2.x имеет собственный профиль и по умолчанию ждёт явного выбора проекта. Предварительный канал сохраняет свой профиль. При ручном переопределении каталога настроек каналы используют отдельные INI.
- Служебная проверка принимает отдельную папку полного набора синтетических фикстур. Отсутствующие материалы дают код 2 до создания выходной папки.
- Windows 11 x64 и Windows Server 2022 x64 являются проверяемыми средами кандидата. Windows 10, экранный доступ, настольный Word, системный DPI и печать требуют самостоятельной приёмки.
- Версии и контрольные суммы Qt и PySide6 указаны в THIRD-PARTY-SOURCES.json. Для будущего выпуска Portable, ThirdParty-Sources, соответствующие исходники программы, лицензии и контрольные суммы передаются вместе.
