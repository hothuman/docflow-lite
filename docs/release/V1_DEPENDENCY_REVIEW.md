# Проверка зависимостей кандидата 1.0

26.10.2026: проверка закреплённых пакетов через OSV нашла GHSA-xmj3-9gf7-h52w в setuptools 84.0.0. Это дефект legacy wheel-install на Windows, исправлен начиная с 84.1.0. Для новой сборки закреплена 84.2.1; это обновление инструмента сборки, не новый механизм приложения. Источник: https://github.com/pypa/setuptools/security/advisories/GHSA-xmj3-9gf7-h52w .

Python 3.13.16 не содержит новых security fixes (в том числе Expat и TemporaryDirectory). Python 3.13.18 доступен только исходниками, свежих бинарников в существующем uv/Actions каталоге нет. Вместо неподтверждённого бинарника используется **официальный CPython 3.14.10 NuGet x64**, без системной установки: SHA256 f54ba67c9951c3d773ea47d2bb095150c037c399f0423a968bcda22809241784; подпись python.exe Valid, Python Software Foundation. Обоснование: https://www.python.org/downloads/release/python-31318/ и https://docs.python.org/3.14/using/windows.html#the-nuget-org-packages . Совместимость 307 тестов проверена локально; новый frozen EXE требует отдельной проверки. Byte-for-byte воспроизводимость EXE не обещается.

Qt 6.10.2 попадает в диапазоны нескольких advisories. Например CVE-2026-16762 (QXmlStreamReader DoS), CVE-2026-101201 (JSON parsing), CVE-2026-6210 (SVG). Продукт не принимает произвольный SVG/Qt JSON/сетевые ответы; XML Office защищён отдельным ограниченным parser. Это снижает применимость, но не основание объявлять старые библиотеки безопасными. Кандидат использует Qt/PySide6/Shiboken 6.12.0 и соответствующие исходники. Источники: https://www.qt.io/blog/cve-2026-16762 , https://www.qt.io/blog/security-advisory-cve-2026-101201 , https://www.qt.io/blog/security-advisory-type-confusion-and-heap-buffer-overflow-vulnerability-in-qt-svg-marker-handling . Windows 10 1809+/11 x64 сохраняются по Qt 6.12 supported-platforms: https://doc.qt.io/qt-6/supported-platforms.html .

Границы: OSV PyPI не покрывает все встроенные C/C++ библиотеки и ещё не опубликованные дефекты. Новые advisories проверяются перед финальным stable; отсутствие найденной записи не означает сертификат безопасности. Подмена исходников/отключение проверок TLS не применялись. Историческая a6 не пересобиралась и не заменялась.

Подпись: Artifact Signing Basic указан Microsoft как $9.99/месяц (https://learn.microsoft.com/en-us/azure/artifact-signing/how-to-change-sku); применимость по стране/статусу/identity validation требует отдельной проверки. Sectigo публикует от $536.25/год при пятилетнем варианте (https://www.sectigo.com/ssl-certificates-tls/code-signing). Это ориентиры источников, не заказ и не обещание доступности владельцу; покупки не выполнены. До фактического подписания EXE остаётся NotSigned, SmartScreen не гарантируется.
