# Работа в Service
1. Выберите Service → Клиенты, добавьте организацию или физлицо без избыточных данных.
2. Оборудование → Добавить: постоянный номер, модель, владелец; serial необязателен.
3. Ремонты → Новый ремонт: выберите аппарат, отдельный номер/автоматическую нумерацию, клиента и жалобу.
4. В карточке сохраните приёмку и дефектовку. Согласование и производственный статус задаются человеком. Черновик можно сохранять до завершения.
5. Добавьте работы/запчасти, quantity, unit, price; редактирование и удаление доступны отдельно. Деньги точно округляются до копейки HALF_UP на позицию.
6. Учтите реальный платёж вручную, если он действительно был. Запись Service не является переводом/чеком. Возврат/аннулирование ошибки остаются в истории. Остаток и производственный статус независимы; переплата отображается отрицательным остатком.
7. Прикрепите материалы и создайте нужный DOCX. Старые версии не перезаписываются. Передайте документы после проверки в согласованном Word.
8. Введите дату и фактическую отметку выдачи; подписи автоматически не появляются.
9. Для повторного ремонта откройте оборудование → Карточка/история → Новое обращение. Старый клиент ремонта и документы сохраняются.

Поиск фильтрует все столбцы без запроса SQL из UI; заголовки сортируют записи. Архивирование не удаляет историю. UI спрашивает о несохранённых правках/опасных действиях и не допускает закрытия во время Job.
