# Безопасность и резервирование
Рабочие данные не находятся в EXE/репозитории. Приложение не отправляет их по сети, не подключает аналитику/ИИ/CRM. Само хранилище и ZIP не шифруются. Ограничьте доступ средствами ОС, согласуйте носители и сроки; перенос данных между компьютерами — ответственность оператора.

Вложения: PNG/JPEG декодируются QImageReader с пределом 32 мегапикселя/128 MiB, MP4 проверяется по контейнеру/дорожкам, DOCX — существующими проверками архива/XML/активных конструкций. Это не антивирусная сертификация и не полная проверка каждого видеокадра. EXE/SVG/произвольные форматы не принимаются. Размер до 250 MiB. Имена/пути определяются UUID, ../, абсолютные пути и символьные ссылки отвергаются. Перед открытием проверяется SHA256.

Backup использует SQLite online backup, включает ссылки из снимка базы и все зарегистрированные вложения/документы. Манифест размеров/SHA256 сверяется с записанными ZIP-данными; затем создаётся новое имя назначения. При нехватке места временный/свой неполный файл удаляется, существующий файл не перезаписывается.

Восстановление: выберите копию и родительскую папку; программа создаст новый каталог, проверит состав, ограничения, CRC/SHA256, SQL-целостность и ссылки. Текущий проект не заменяется. Откройте восстановленный проект, сверяйте ремонты/вложения/документы до использования. Не удаляйте исходную копию до приёмки.

Нет автоматического удаления ремонтной истории через 30 дней. Сроки данных DocFlow Lite как исполнителя не определяют сроки базы ремонтной организации. РКН/правовые основания/поручение остаются отдельными нерешёнными условиями реального внедрения, PR №4 не утверждался этим этапом.
