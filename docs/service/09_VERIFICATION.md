# Проверка реализации
Исходная база: 129 tests + 16 subtests passed на Linux до изменений. Первый сквозной тест выявил неподдерживаемый разрыв строки рядом с переменной; исправлен шаблон, защита Core сохранена. Тест повторных ремонтов выявил неоднозначный порядок записей с одинаковыми датами до секунды; добавлен стабильный tie-break по rowid. Промежуточная проверка сайта обнаружила ещё не скопированный service.png; добавлен реальный снимок Qt-программы.

На текущем шаге подтверждены 9 сценариев Service runtime на Linux/offscreen: пустой проект, реальные Qt-диалоги, точные расчёты, 5 типов/6 версий DOCX, повторный ремонт, backup/restore со всеми файлами, перезапуск, Core-демо, нормальное закрытие. Автотесты включают реальную БД, а не mock-хранилище.

Итоговые число тестов, SHA, нативный Windows и браузерные результаты записываются по фактическому запуску в отчёт передачи. Никакая подготовленная конфигурация не считается успешным Windows/Chromium-тестом сама по себе.
