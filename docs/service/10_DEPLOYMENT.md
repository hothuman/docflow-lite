# Передача для проверки
Это alpha 0.3.0a1, не официальный Release. Существующий публичный v0.1.1 не меняется. Для исходников Python 3.11–3.13: `pip install -e ".[gui,dev]"`, запуск `python launch.py`. Для Windows используйте весь Portable ZIP с _internal; Python пользователю не нужен. Точные условия — README-WINDOWS-SERVICE.txt.

В Service настройках откройте папку project из отдельного синтетического набора либо создайте собственное пустое локальное хранилище. Не открывайте одну SQLite-базу по сети/с двух экземпляров. Перед реальным внедрением выполните ручные A–I сценарии, проверьте Word, копию/восстановление, права доступа и согласованные исходные формы.

Сайт собирается прежним `PUBLIC_SITE_URL=https://docflow-lite.pages.dev/ ENABLE_INDEXING=0 python site/scripts/build_site.py`. Результат — только ZIP для предварительного рассмотрения. Никакого Direct Upload этим шагом нет. Перед разрешённой публикацией сверить пересечение контактов/политики/условий с PR №4; не переносить черновики как утверждённые. Не включать noindex/form/payments автоматически.

Публикация, merge и официальный Release требуют отдельного решения владельца. Реальные файлы клиента и рабочая база не должны войти в Git, сайт или CI-артефакты. Оставьте только вымышленные fixtures.
