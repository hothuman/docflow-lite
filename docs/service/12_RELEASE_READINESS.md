# Готовность к выпуску

Service — отдельный поток разработки 01–10 внутри DocFlow Lite. Core Master Plan 01–07 и юридический этап 05/07 автоматически не закрыты. DocPerfect и ASHROUTE не добавлялись.

Alpha 0.3.0a1 реализована в feature/docflow-lite-service и проходит реальные Linux/Windows автоматические проверки и Chromium. Готова к ручной проверке владельцем и обсуждению пилота. Это не стабильный промышленный выпуск. Подробные доказательства и границы: 09_VERIFICATION.md и 15_HANDOFF_REPORT.md.

Публичный Release остаётся v0.1.1, main — 0.2.0rc1. Новый Portable передаётся через CI без официального Release/тега. Сайт с двумя направлениями подготовлен, в production не загружен. PR №5 draft, merge запрещён без отдельного решения. PR №4 не изменялся и не объединялся.

Нативный Windows Server 2022 runner подтверждает запуск EXE, Core, девять Service-сценариев, реальные SQLite/файлы и backup/restore. Физический Windows 10/11, нативные OS file-dialogs, SmartScreen и Microsoft Word требуют ручной проверки. Исходный сложный акт и импорт истории должны быть адаптированы после ответов заказчика; нейтральные формы не заменяют утверждённый формат.

Сохранены LGPL notices/сопутствующие исходники прежнего процесса упаковки; Qt DLL внешние в onedir. Service не добавляет обязательную коммерческую лицензию и не заявляет юридическую сертификацию LGPL/собственных прав. Вопросы достаточности corresponding source и замены библиотек из PR №4 остаются открыты.

Не сделаны: production deployment, merge, Release/теги, включение платежей/формы/индексации, реальное внедрение/импорт клиентской базы, договор и утверждение условий акта. До внедрения: ручные сценарии A–I, форма/данные/хранение/резервирование и точный объём, затем отдельное разрешение владельца. Не было вымышленных продаж, клиентов, подписей или получения денег.

Рабочая среда отключилась во время финальной упаковки. Код/документация остаются в PR; воспроизводимый комплект создаётся Service review handoff CI из зафиксированных успешных артефактов. Не называйте локальный временный файл доступным, если он не передан. Скачайте CI-комплект до истечения срока хранения.
