# Демонстрация пилота
Это подготовительная версия на полностью вымышленных данных, не подтверждённое внедрение или выполненный платный заказ.

1. Распакуйте весь Windows Portable, откройте Service → Настройки → отдельное синтетическое демо либо проект из переданного набора.
2. Покажите постоянную карточку аппарата и два обращения, историю, независимые статус/остаток. Создайте новое обращение; прошлое не исчезает.
3. Откройте дефектовку, добавьте работу и деталь с дробным количеством, проверьте сумму. Покажите внутреннюю оплату/возврат — без реальных переводов.
4. Прикрепите учебное фото/MP4, создайте приёмку и выполненные работы, откройте DOCX в целевом Word. Измените карточку и создайте следующую версию.
5. Создайте копию и восстановите в новую папку, откройте проект после перезапуска.
6. Вернитесь в Core: XLSX/CSV → два DOCX и отчёт из прежнего демо.

Сверьте с реальным процессом: какие колонки/условия/даты/фотографии отличаются? Зафиксируйте расхождения и критерии приёмки. Не передавайте рабочий журнал до согласования законного маршрута данных. Стоимость и срок внедрения определяются отдельно, не этим сценарием.
