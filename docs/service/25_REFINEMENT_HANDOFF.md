## Исправления в рамках CP

- Core: сохранение профиля больше не блокирует GUI; неудачный новый запуск не показывает успех предыдущего. Существующая генерация и синхронный API сохранены.
- Service: повтор request_id с другим способом, основанием или датой внутренней оплаты отклоняется без изменения исходной записи.
- Экспорт вложений: ограниченное чтение, SHA256, exclusive-create, уборка недописанного файла. Restore публикует проверенную копию атомарно без замены уже появившейся папки.
- GUI: общий графитовый фон/винные акценты, локализованные деньги и даты, адаптивные колонки с полным tooltip, пользовательская ширина, быстрый локальный поиск. Обзор показывает настоящие показатели и последние обращения. Карточка разделена на «Основное», «Стоимость», «Материалы», кнопки остаются внизу вне прокрутки.
- Формы импорта, смет и организаций доступны; ручное согласование не выдаётся за отправку клиенту. Сохранены профили и реквизиты старых документов.
- Qt: корректное удаление закрытых окон в GUI-потоке; отдельно проверены12 циклов открытия/закрытия/принудительной уборки мусора.
- Устранена лишняя сортировка всего журнала при открытии и нарушение исходной хронологии истории. Сортировка по нажатию заголовка сохранена.
- В Windows при визуальном просмотре найден белый Aero-footer QWizard; введён ClassicStyle. Новый native gate во всех5 размерах получил `#0d0f13`, кнопки доступны. Есть PNG до/после.
- Исправлен платформозависимый тест фона: прежняя точка попадала в белый глиф QLabel. Порог темноты не ослаблен, проверяются открытые участки фона. Первый неуспешный Windows traceback сохранён; ошибки не скрыты.
- Упаковщик больше не использует устаревшие константы a2: требует реальные успешные CI одного HEAD, проверяет версию, точные исходники, EXE/ZIP, итоговую базу и её реальное восстановление.
