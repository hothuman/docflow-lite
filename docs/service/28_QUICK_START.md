# Начало работы с DocFlow 0.3.0a4

DocFlow работает на вашем компьютере. Core / Lite создаёт документы из таблицы; Service хранит клиентов, оборудование и отдельные обращения в локальном проекте.

## Запуск и переключение

Распакуйте весь Portable. Сохраните `_internal` рядом с EXE. Сверьте SHA256 из комплекта. Выберите Core или Service в списке в верхней части боковой панели. Разделы выбранного направления показаны ниже; при переключении загруженные данные Core и открытый проект Service сохраняются.

## Core

1. Откройте встроенный демопример либо выберите XLSX/CSV и свои DOCX-шаблоны.
2. В «Поля и проверки» сопоставьте переменные и столбцы. При необходимости укажите лист XLSX или кодировку CSV и перечитайте таблицу.
3. Проверьте записи и выберите папку результата. Запустите генерацию.
4. В «Результат» откройте файлы и отчёт. Ошибочные записи отражены в отчёте; успешность предыдущего запуска не подменяет ошибку нового.
5. Сохраните JSON-профиль для повторной работы. Исходные файлы не перезаписываются.

## Service

1. Начните с отдельного демопроекта: Service → Настройки → Создать отдельное демо.
2. Для чистого проекта добавьте клиента, затем оборудование. Номер аппарата постоянный; номер ремонта относится к отдельному обращению.
3. Создайте ремонт. В карточке разделы «Основное», «Стоимость», «Материалы» открывают приёмку, дефектовку, позиции, сметы, оплаты, вложения и DOCX.
4. Сохраните черновик предварительного расчёта, затем создайте версию. Старые версии неизменяемы. Согласование является ручной отметкой, а не отправкой клиенту.
5. Фактические позиции определяют стоимость ремонта. Оплаты и возвраты — внутренний учёт, не движение денег.
6. Для повторного обращения откройте тот же аппарат и создайте новый ремонт. История прежнего обращения сохраняется.

## Обновление и восстановление

Закройте приложение и сделайте резервную копию до обновления. Распакуйте новую версию в другую папку. Не заменяйте и не удаляйте папку проекта. Откройте её через Настройки → Открыть другой проект. Схема базы проверяется при открытии; старый EXE может не понимать новую схему, поэтому для отката используйте копию до обновления в новой папке.

Копия включает базу, связанные документы, вложения и шаблоны. Восстанавливайте только в новую папку. Откройте результат и проверьте записи и файлы. Храните копии отдельно от рабочей папки с ограниченным доступом; архив не зашифрован.

Ширины таблиц сохраняются в `interface.ini` в пользовательской конфигурации DocFlow. Старые значения из реестра читаются для переноса. При отказе записи изменение остаётся в текущем окне, а подсказка заголовка таблицы объясняет проблему. Файлы проекта от настроек интерфейса не зависят.

## Проверка именно новой версии

Не нужно повторять всю вчерашнюю приёмку a3. В a4 проверьте переключение направлений, новую боковую навигацию, обзор, настройки, ширины таблиц и историю при небольшом окне. Сгенерируйте один знакомый комплект и откройте в вашей версии Word. Если найден дефект, запишите экран, действие и ожидаемый результат.
