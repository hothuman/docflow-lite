# DocFlow 0.3.0a4 — передача изменений

25 октября 2026, МСК. Основа — bba13c9. Новая итерация меняет рабочее пространство, не переписывает проверенный домен Core/Service.

## Результат

Явный переключатель Core/Service и контекстная боковая навигация заменяют конкурирующие уровни меню. Состояние направлений сохраняется. Обзор показывает реальные показатели, компактный список обращений и быстрые действия. Настройки разделены по задачам. Обновлены общие стили.

Предпочтения ширин сохраняются в INI без необходимости записи в реестр. Значения старых установок читаются для переноса. При отказе сохранения текущая ширина остаётся в окне, пользователь получает объяснение. История оборудования прокручивается на небольших окнах; дефект выявлен на виртуальном 200% и исправлен. Повторный щелчок по активному разделу больше не снимает выделение.

Сайт получил сравнение направлений, описание пилота, новый Core preview и настоящие Windows/Qt снимки a4. Ссылки публичного скачивания остаются v0.1.1. Формы, индексация и аналитика выключены, production не менялся.

## Проверки и доказательства

База до изменений: 245 passed +16 subtests, `refresh-baseline.xml`. После первой реализации — 245+16. Добавлены регрессии сохранения состояния при переключении и отказа сохранения предпочтений. Финальный результат и точный SHA содержатся в поставляемом `VERIFICATION.json` и JUnit XML; незавершённый прогон не считается успешным.

Нативные Qt layout-проверки: 90 случаев при 100% и 90 при 200%; история первоначально не помещалась на двух малых размерах при 200%, затем все 90 повторно прошли. Это виртуальные клиентские размеры, не физический DPI монитора.

Chromium 151.0.7922.34: восьмиширинная проверка 320–1280, меню, FAQ, клавиатура, no-JS и реальная загрузка демо. `browser-checks.json`: passed, 0 script errors, 0 external requests, 0 data writes. Исходный Edge запуск в sandbox не удался; используется отдельно установленный тестовый Chromium, отказ Edge не скрыт.

Windows Portable собирается локально на CPython 3.12.10 x64, допустимом проектом, с PyInstaller 6.22.3 и закреплёнными runtime-зависимостями проекта. Это не прежний CI на 3.13.16 и не побайтово воспроизводимая копия a3. Лицензии собираются из реально установленных пакетов; источники Qt/PySide проверяются по закреплённым SHA. Проверка точного frozen EXE и происхождение комплекта отражаются в `WINDOWS-LOCAL-RESULTS.json`, `BUILD-INFO.json`, `SOURCE-PROVENANCE.json`.

Генератор DOCX не менялся. Попытка нового визуального рендера через штатный render_docx.py остановилась с `LibreOffice soffice.exe was not found on PATH`. Microsoft Word не установлен. ZIP/XML и сценарии генерации проверяются автоматически; новая визуальная приёмка DOCX остаётся NOT VERIFIED. Старые 63 страницы a3 не выдаются за новую проверку.

## Поставка и ограничения

Portable распаковывается целиком в новую папку; данные проекта остаются отдельно. Перед обновлением — проверенная копия. Установщик отложен как необязательный для этой alpha; цифровая подпись требует сертификата владельца и не имитируется.

Клиентская адаптация BLOCKED до обезличенного Excel, правил номеров/связей и утверждённых форм/гарантии. Подготовлены карта материалов и сценарий пробного переноса. Коммерческие документы — проекты, реквизиты и условия не выдуманы. Юридический PR4 прочитан отдельно и не объединён; правовая готовность не заявляется.

Остаются физический DPI и системные файловые диалоги владельца, Word, утверждение клиентских форм/условий и решение о выпуске. Вчерашняя приёмка a3 принята как факт проверенных владельцем сценариев, без требования повторить её целиком. Для a4 требуется проверка изменённых экранов и знакомого комплекта.

Merge, Release/теги, Cloudflare deployment, включение форм/платежей/аналитики/индексации и отправка сообщений не выполнялись.
