## Дополнение 25.10.2026: единый стандарт и выпуск

Добавлены корневой AGENTS.md, переносимая копия стандарта, актуальный README без конфликтующих статусов a3/a4/a5, заметки a6 и порядок выпуска. Условия лицензий, правообладатели и бренд сохранены. Workflow больше не привязан к v0.1.1 и создаёт только draft после проверок. Новый build_release_site.py разрешает активировать загрузку a6 только после проверки реально опубликованного prerelease, target commit и SHA256 файлов. Для этого пути добавлены регрессии отказов и успешного перехода на синтетических данных. Текущие результаты нового прогона записываются в комплект подготовки; прежние 260+16 относятся к базе приложения 0d4fd5e.

Свежий итог подготовки: 268 passed +20 subtests, без пропусков; Chromium — восемь ширин, реальные скачивание/хеш демо, no-JS, ноль ошибок/внешних запросов/записей. Сделано явное чтение UTF-8 в проверках сайта. Регрессия импорта теперь намеренно воспроизводит совпадение поиска с внутренним UUID и проверяет смету нужного номера обращения; проверка позиций и сумм сохранена. Код приложения не менялся.
