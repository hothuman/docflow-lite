# QA SAMPLE — учебные данные Stage8

Это полностью синтетический комплект, не документы и не реквизиты КлинТек. Реальную базу для обучения не открывайте.

1. Создайте новый пустой проект в «Мастерской». Откройте настройки → импорт истории XLSX/CSV.
2. Выберите `journal-qa.xlsx`, прочитайте листы и выберите «Журнал». Для CSV выберите одноимённый вариант и соответствующую кодировку. У всех CSV разделитель `;`.
3. На шаге колонок проверьте предложения. Номер обращения и постоянный номер аппарата — разные поля. Отдельно сопоставьте ID/название клиента и ID/название собственника. «Полнота оплат (known / unknown)» соответствует одноимённому полю. Пустые суммы не означают ноль.
4. На шаге связей явно подтвердите новых клиентов и аппараты. Статус источника «Принято» сопоставьте со статусом «Принято». Собственник — QA Собственник, заказчики — QA Заказчик А/Б. Не объединяйте их.
5. В предпросмотре ожидаются три обращения, два аппарата (0007 и 0008) и три лица. Для QA-R3 стоимость и оплаты неизвестны. Для QA-R1 итог 100,01 ₽, оплата 20,01 ₽, остаток 80,00 ₽. Подтвердите только проверенные строки.
6. Повторите тот же импорт с тем же постоянным ID источника: новых обращений быть не должно. Изменённую старую строку программа должна отметить конфликтом, а не переписать молча.

`catalog-1c-qa.xlsx` — учебный каталог, а не подтверждённый формат 1С заказчика. Выберите лист «Каталог»; сопоставьте код, артикул, название, тип, цену и валюту. Внешние коды 00007/00008 должны сохранить ведущие нули. Обновление цены включается явно и не меняет старые сметы.

В `Templates-QA` находятся шесть вымышленных бланков. В настройках исполнителя выберите шаблон и откройте «Поля шаблона». Поля «Собственник», «Заказчик», «НомерОбращения» обязательны. Для гарантии поле «УсловияГарантии» требует отдельно введённого текста: образец не устанавливает реальные гарантийные обязательства. Настройки JSON приложены как описание примера; пользователь может выполнить настройку через интерфейс.

Перед реальным переносом сделайте резервную копию и восстановите её в новую папку. Не переносите пробную базу поверх рабочей. QA-03, проверка Word, печати и приёмка владельца остаются открытыми.
