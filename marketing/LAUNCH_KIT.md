# Материалы запуска DocFlow

Черновики для публикации владельцем после проверки публичного выпуска. Автоматическая рассылка не выполняется.

## Короткое описание

DocFlow — документы и история ремонта на вашем компьютере. Core создаёт DOCX из XLSX/CSV и ваших шаблонов. Service хранит оборудование, обращения, сметы, документы и внутренние финансовые записи в локальном проекте.

## Подходящие задачи

Повторяющиеся комплекты документов из таблицы; локальная мастерская с историей аппаратов и обращений; согласованная настройка шаблонов. Один оператор. Совместная сетевая база, касса, банк и облачная синхронизация в эту версию не входят.

## Объявление

Подготовил DocFlow Core + Service для Windows. Core помогает получить комплект DOCX из таблицы и своих шаблонов. Service ведёт историю оборудования и ремонтов, сметы и документы в локальном проекте.

Программа бесплатна, Python для Portable не нужен. Версия предварительная: сначала стоит пройти демо и проверить свои документы на копии данных.

Индивидуальную настройку таблицы и шаблонов можно обсудить отдельно. Для первого сообщения достаточно описать процесс без данных клиентов.

## Демонстрация на 3–5 минут

1. Показать выбор Core/Service.
2. Загрузить встроенное Core-демо, показать две корректные записи и одну ошибочную.
3. Создать четыре DOCX и открыть отчёт.
4. В отдельном Service-демо найти аппарат и историю обращений.
5. Показать черновик и сохранённую смету, ручную отметку согласования и внутренний баланс.
6. Открыть документ и показать резервирование в новую папку.

Демонстрация содержит только вымышленные данные. Ролик demo.mp4 содержит восемь настоящих состояний Core и Service a6 по пять секунд. Это последовательность кадров исходного приложения с синтетическими данными, без звука; не запись времени операции и не доказательство frozen EXE. Скрипт воспроизведения: scripts/capture_demo.py.

## Первый ответ

Здравствуйте. Опишите, какие документы вы готовите, откуда берутся данные и какой результат нужен. Для первичной оценки достаточно обезличенного примера. После проверки формата согласуем состав, цену, срок и критерии приёмки.
