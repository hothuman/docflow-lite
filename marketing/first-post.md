# Первый демонстрационный материал

Статус: подготовлен; не опубликован. В ролике 24 секунды кадров реального приложения, без озвучки. Встроены только вымышленные данные. Ролик показывает последовательность состояний; это не замер времени генерации.

## Текст публикации

Заполняешь одни и те же документы из Excel вручную?

Сделал DocFlow Lite: выбираешь таблицу, добавляешь свои шаблоны Word и сопоставляешь поля. Из одной записи можно получить сразу несколько DOCX.

В этом примере — заявка и подтверждение. Две записи проходят проверку, а третья пропускается: в ней нет услуги и указана отрицательная сумма. Ошибки остаются в отчёте.

Обработка локальная. Это первая бета: для запуска нужен Python 3.12, предпросмотр пока текстовый. Оформление готовых файлов нужно проверить в Word.

## Кадры уже подготовленного ролика

| Время | Содержание |
| --- | --- |
| 0–6 с | Таблица с тремя записями и два шаблона |
| 6–12 с | Текстовый просмотр первой заявки |
| 12–18 с | Проблемная запись: пустая услуга, отрицательная сумма |
| 18–24 с | Реально полученный результат: четыре DOCX, одна пропущенная запись |

Первый материал рассчитан на обычную публикацию в выбранном основателем канале или сообществе, где разрешены такие демонстрации. Подготовленный ролик горизонтальный; вертикальный монтаж под клипы ещё не сделан. Перед публикацией нужно утвердить площадку, контакт и действующую ссылку. Материал не содержит отзывов, клиентских кейсов и заявлений о подтверждённой экономии времени.
