# DocFlow Lite 0.1.1 — существующий сайт

Исходный дизайн, демопример, приложение, изображения и видео сохранены. Публикуется только `dist/`. Контакты — Telegram @de1grace и rostg2007@gmail.com; телефон не размещается. Бесплатная Windows portable-сборка не требует установки Python. Для отдельного демо из исходников нужен Python 3.12. Платная настройка — от 5 000 ₽ с предварительным согласованием окончательной цены. Заявку посетитель отправляет самостоятельно в Telegram или почте.

## Публикация

Существующий сайт опубликован через Sites: https://docflow-lite.rostg2007.chatgpt.site/ . Публикация подтверждена хостингом и анонимными HTTP-запросами. ZIP и видео реально получены кнопками публичного сайта; SHA256 совпали с исходниками. Протоколы и ограничения находятся в отчёте этапа 02. Репозиторий проекта: https://github.com/hothuman/docflow-lite . Служебное Git-хранилище Sites и этот репозиторий GitHub — отдельные хранилища одного сайта.

Метаданные текущего `dist/` настроены для этого адреса. `scripts/configure_public_url.py` поддерживает HTTPS-адреса как в корне, так и в подкаталогах GitHub Pages; тесты запускаются командой `python3 -m unittest discover -s site/tests -v` из корня полного проекта. Сам скрипт запускается из корня полного проекта как `python3 site/scripts/configure_public_url.py РЕАЛЬНЫЙ_АДРЕС`.

Скрипт обновляет canonical/og:url всех трёх HTML, абсолютный og:image, robots и sitemap. Относительные ссылки на страницы и ресурсы сохраняются. Sitemap включает только индексируемые страницы. На GitHub Pages с подкаталогом проектный robots.txt доступен внутри подкаталога, но правила роботов всего origin определяются файлом в корне origin; метатеги robots остаются действующими на страницах.

Главная — index,follow. Условия и конфиденциальность остаются noindex,follow до утверждения полных сведений об исполнителе и обработке коммерческих обращений. Не добавлены оплаты, аналитика, трекеры, вымышленные отзывы или собственная открытая лицензия.

## GitHub Pages

В полном проекте подготовлен `.github/workflows/pages.yml` для ручного запуска. Он берёт фактический `base_url` из actions/configure-pages, проверяет скрипт, настраивает метаданные и публикует только `site/dist/`. Репозиторий GitHub создан; этот дополнительный Pages workflow ещё не запускался. Для бесплатного Pages на GitHub Free нужен публичный репозиторий и источник Pages = GitHub Actions. Текущая рабочая публикация находится в Sites и не зависит от запуска Pages.

## Границы

Windows portable-бета опубликована: https://github.com/hothuman/docflow-lite/releases/tag/v0.1.1 . Прямая ссылка на реальный ZIP добавлена на существующий сайт; отдельная кнопка демо из исходников сохранена. EXE проверен автоматически на Windows Server 2022, ручная проверка Windows 10/11 ещё не выполнена. Доставка сообщения в Telegram/email проверяется получателем; сайт не создаёт автоматического подтверждения отправки. Страницы содержат техническое описание обработки, а не подтверждение полной юридической готовности. Исторический отчёт этапа 01 сохранён отдельно.

## Коммерческая часть, этап 04

Главный сегмент первых продаж — малые сервисные компании и подрядчики с простыми DOCX. Два предложения: один шаблон от 5 000 ₽ и комплект до трёх от 9 000 ₽, без подписки на программу. В `#services` опубликованы состав и ограничения, в `#setup` — порядок обращения, рядом FAQ и PDF-предложение. Сообщения отправляет посетитель в Telegram/email. Сведения об исполнителе и получение оплаты требуют уточнения до первого платного заказа. Юридические страницы остаются noindex. Технические результаты этапа 04 передаются отдельно; EXE и релиз не изменялись.
